# 证券目录初次搜索防抖覆盖分页

2026-10-30最终整合回归发现目录分页用例产生额外请求。单独运行偶尔通过，
并行负载下失败。确定性假时钟回归证明：初次渲染即安排250毫秒搜索防抖，
即使搜索内容未改变，定时器也会把用户已选页码重置为1。

## 根因与修复

排除了无效跳转校验、查询键错误和远端数据变化；请求mock与页码状态证明
额外请求来自初次防抖的`setPage(1)`。仅在搜索文本与当前查询不同时安排
防抖；实际搜索、清空搜索与筛选后的分页重置仍沿原流程。

## 回归与验证

`StockCatalogDialog.test.tsx`新增假时钟用例：先到第2页，再推进300毫秒，
断言页码和请求数保持。原实现明确失败；修复后及反转复核的实际结果记录在
[整合验证记录](../../../reports/current-release-20261030/verification.md)。

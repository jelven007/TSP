# Bug：结果归档更新重置页签，配置模块加载错误升级为整页错误

Status: VERIFIED
Mode: default
Severity: functional

## 用户现象

选择自定义S02结果后盘中经常从选/买切回卖。
点击列表配置出现“Unexpected Application Error!”。

## 已核实

`Screener.resultViewKey`包含record_id，dailyView与该键绑定；
键变化的effect清空dailyView，因此每份新归档会将页签恢复为卖。
实际线上新浏览器可以打开列表配置，无pageerror或失败资源。
`ListColumnCustomizer`直接挂载React.lazy子组件，只有Suspense而没有局部错误边界，
模块加载错误可直接升级到上层路由错误。

## 假设与验证

| 配置模块加载/渲染失败未被局部隔离 | 注入复现并修复 | 原壳错误升级路由；局部边界修复后反馈、保留结果及重试通过 |
| 正常配置按钮每次必现原错误 | 已排除 | 真实线上新浏览器成功打开 |

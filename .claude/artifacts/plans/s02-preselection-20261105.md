# S02 盘后预选 Implementation Plan

> **For agentic workers:** 按当前已授权实施范围在隔离工作目录逐项执行，不提交或发布。

**Goal:** 前交易日北京时间16:00开始生成并保存下一交易日的选名单，买只从该名单内触发。

**Architecture:** L3内部接线，复用Screener日线加载、选股纯函数、StrategyResults归档和现有定时Worker/Compute。预选独立日期记录保存冻结身份及源日期，日内结果保持原配置身份；读取无日内结果时可返回已保存的预选。入场资格冻结，持仓出场及完整股票池独立。

**Tech Stack:** Python/Polars、SQLite及租户PostgreSQL documents、React/TypeScript、现有Compute。

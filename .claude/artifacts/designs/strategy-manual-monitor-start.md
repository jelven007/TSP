# 策略选择与监控启动

2026-11-01。授权范围：用户要求首次选择策略不立即执行，点击策略监控再执行，
此时日期默认最近交易日。基线v0.4.41；包含工作区既有参数修改，保留原内容。

采用L3页面事件调整，复用`Screener`、`StrategyCard`、现有监控规则API、
共享数据画像和日期维度查询键，不新增扩展接口。

选择卡片、加入策略池、新建普通或叠加策略只修改选择／池，读取已保存结果。
页面挂载、日期变化和已有监控规则不发起页面自动补算。
手动重载和已有参数保存重算保持原行为。

点击开启监控时从共享`dataStatus.enriched.latest_date`取得最近本地可用交易日，
将当前日期／选中策略切到该上下文。不会用浏览器自然日或工作日猜测节假日；
日期未就绪时提示重试，不保存规则、不执行。仅监控规则保存成功后，
按策略声明的1d／1m调用单策略执行。已有保存结果不跳过此次显式执行。

取消监控只删除规则。监控保存／删除失败显示错误；同一策略的并发点击合并为一次。
执行中的日期／策略切换仍隔离迟到结果，后台完成不改回用户新选择。

验收：首次选择／入池／新建零执行；已有监控挂载或切历史日期零补算；
日线和分钟监控正确日期／周期且只执行一次；保存未完成／失败不执行；
缺日期不启用；取消不执行；迟到结果不覆盖新视图；旧日期归档查询仍可恢复。
验证定向测试、前端构建／Lint、隔离浏览器交互及文档引用。
不修改应用版本、不提交、不推送；更新现有本地前端副本，线上不部署。

# 模拟账户修改和删除

来源：用户要求在模拟页面修改、删除账号，并同步处理关联内容。
范围：L3 核心生命周期，复用 paper 领域、租户事务、Query 和公共弹窗。

## 验收

- AC-1：修改名称、费用、涨跌停排队；名称与设置同步到概览、列表和对比。
  账号 ID 保持稳定。费用仅作用于后续成交，历史成交、权益账本和统计不改写。
- AC-2：仅无任何委托、成交、持仓、净值记录的账户可改初始资金；
  成功同时更新现金和总资产。非法字段、数值或已产生记录时整体拒绝修改。
- AC-3：明确确认删除后清理账户、委托、成交/权益、持仓、净值、
  自动规则、事件回执、退出待办/归档、风险与跳过记录、可识别的账户提醒和待发送通知。
  其他账户、其他租户、共享策略与监控规则保留。
- AC-4：删除与撮合/结算互斥；已删除 ID 的读取和旧任务不得重建目录或写回数据。
  文件路径越界、符号链接及权限失败必须明确拒绝。SQL 使用原权限和租户事务。
- AC-5：修改、删除刷新列表、对比曲线和关联提醒；取消旧请求并删除目标账户缓存。
  删除展开面板或最后一户后正确回到列表/空态，失败保持数据和重试入口。

## 兼容

旧创建、设置、冻结 API 保留；新增 PUT/DELETE `/api/paper/account?account=...`。
文件目录沿原布局；SQL schema 8 为账户子表新增删除级联，保留成交表禁止直接修改/删除。
旧缺 account_id 的提醒仅在能确证所属账户时处理，不能根据相似名称误删。
本次不提交、推送、回测、迁移运行数据库或部署，不修改应用版本。

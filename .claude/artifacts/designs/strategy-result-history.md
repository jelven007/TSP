# 策略结果持久化与日期恢复

状态：本地实现与隔离验证完成；已纳入2026-10-25授权整合发布。
本地不手动递增版本，远程main合并后的CI分配应用版本。
本批全量与部署证据见[整合记录](../../../reports/current-state-release-20261025/verification.md)。

## 结论与架构

策略结果归档成为权威记录，内存仅缓存已持久化记录。多租户复用
`business.documents` 的 PostgreSQL 事务与 RLS；本地使用
`data/user_data/strategy_results.sqlite3`。不引入 ClickHouse，不迁移生产数据库。
旧 `strategy_cache` 保留当前盘后/实时兼容用途，清空旧缓存不删除归档。

```
策略定义与有效参数 -> 执行上下文指纹 -> 策略计算
  -> 成功结果事务持久化 -> 查询摘要/明细 -> 有界内存缓存 -> 页面
日期切换 -> 按当前定义与有效参数查询该日 -> 命中恢复；缺失按原自动运行开关计算
历史结果入口 -> 当前租户/策略历史列表 -> 选择旧定义与参数快照 -> 归档明细
```

## 记录与唯一键

租户由可信服务端上下文取得，不接受浏览器指定；本地以数据目录隔离。
持久化字段：稳定策略 ID、当时策略名称、逻辑版本、有效参数/计算覆盖配置及指纹、
资产、周期、实际计算日期、计算时间、输入世代/公共发布标识、结果行和曾命中行。
名称参与记录维度，稳定 ID 串联改名历史。版本采用逻辑内容指纹，注释/展示名称
变化不产生逻辑新版本；子策略逻辑与会影响计算的自定义依赖纳入身份。
参数字典排序规范化，默认值解析后归档；股票池约束也是计算输入。

同一完整维度保留最近成功结果及同日曾命中并集，不为每次刷新无限创建副本。
不同名称、版本、参数、资产、周期、日期不相互覆盖。
长任务在启动时捕获身份，配置修改不能把老任务结果标为新配置；
较晚完成的旧启动任务不得覆盖新启动任务的结果。

## 生命周期与责任

| 环节 | 行为与责任 |
| --- | --- |
| 写入 | 策略单跑、批跑和旧策略执行入口先归档成功结果；失败写入明确报错 |
| 阅读 | 缓存摘要和明细接口增加可选日期、资产、周期；服务端匹配当前身份 |
| 历史 | 分页返回归档摘要，按记录 ID 读取旧快照；同时校验租户与策略 ID |
| 失效 | 版本/参数/名称变化改变查询身份；旧记录保留，可在历史入口读取 |
| 内存 | 按租户/本地目录和记录 ID 隔离，限制字节数；跨进程以记录修订验证 |
| 新鲜度 | 已保存结果显示计算时间；手动重跑刷新同一维度，不因缓存 TTL 删除历史 |
| 冷启动 | 从持久记录读取；读失败显示错误，不伪装为无结果触发计算风暴 |
| 缺失 | 复用原渐进单飞与全局资源准入；单飞键包含配置身份，避免异参搭车 |
| 失败 | 计算或持久化失败不覆盖上一成功记录，空成功结果仍须归档 |
| 修复 | 重新运行指定维度；清理热缓存只影响加速，历史无自动过期/删除 |

单条记录沿用16MiB业务JSON上限，摘要查询不加载全部股票行。
历史仓库使用专门的事务查询与确定性记录键，不套用配置列表2000条上限；
所有查询仍经过租户事务/RLS。历史列表分页，不全量载入多年记录。
日志记录保存成功和持久化失败，不输出策略源码、凭据或整份私有结果。
数据库/文件备份包括结果归档；空间增长由运维监测，不自动删除用户历史。

## 兼容边界

旧API无日期参数时继续原当前快照语义；前端新日期读请求明确携带日期。
旧缓存缺版本/有效参数证据，不自动标记为当前版本命中，不虚构已经覆盖的历史。
分钟结果按真实结果日期归档，日线与分钟隔离；页面切日期不将最新分钟结果冒充旧日。
当前实时监控刷新与归档计算快照分别标识，不把历史结果叠加为今日实时结果。
UI筛选、列投影不改变计算身份；扩展列继续在返回边界投影，避免污染归档。

1. 版本/身份规范化与本地/租户持久仓库，先测日期隔离、参数隔离、重启、失败保留。
2. 单跑/批跑归档与日期查询；先测单跑初次落盘、跨日恢复、旧任务/新配置隔离。
3. 前端日期查询键及迟到响应保护，增加分页历史选择，保持现有策略页布局。
4. 更新需求、架构、用户/运维、测试文档；受影响后端测试、Ruff新增范围、
   前端测试/构建、桌面与窄屏模拟接口联调、`make check`。

验收必须证明：A日→B日→A日恢复原结果且不重算；重启后可恢复；
同名不同ID/不同版本/参数/资产/周期隔离；旧版本能显式查看；
无权限读拒绝、跨租户不可见；执行异常不写成功；写盘失败明确反馈；
清缓存不删归档；摘要不携带股票行；前端旧日期响应不回跳当前日期。

真实PostgreSQL、Docker或生产容量未执行时单列限制，不由本地测试外推签收。

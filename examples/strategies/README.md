# 策略源码示例

## S01 卖／选／买候选（2026-11-18）

`s01_signal_sections.py`从本次核实的`custom_mvxxcs01`保存源码复制，
仅追加`META["result_sections"] = "signals"`，使用现有每日信号、预选及历史归档链路。
配套后端须支持S01可选触发器接入每日结果；模板文件本身不会安装或保存运行配置。
保留原基础过滤、信号稳定ID、评分、可用分钟口径；不复制S02的ATR及交易建议。
当前覆盖配置和自定义信号应通过现有保存入口保留，不能因示例自动转换旧冻结定义。
卖是前交易日成功买入信号名单，选是冻结盘后预选，买是当日预选内的实际入场信号，
三者均不等于成交。详见[S01当前说明](../../docs/reference/s01.md)。

## S02 策略示例

`s02_atr14.py`是可由现有`StrategyEngine`加载的完整`minute_filter`源码，
保持策略ID `custom_mvxxcp88`和`result_sections=signals`契约。本目录跟随现行约定，
不作为旧回测的冻结输入；历史研究须使用对应任务自身的源码、覆盖及信号快照。
示例与运行保存值分别核对，当前策略契约见[S02说明](../../docs/reference/s02.md)。

源码使用已有安全只读接口`app.strategy.market_data.previous_session(day)`：
它调用既有已发布交易日历，未知日期抛错，不以行情中最后一根日K代替准确前交易日。
它不创建数据连接或启动服务。

配套`s02_atr14.overrides.json`提供当前基础过滤与排序覆盖，`overlay_filter=[]`。
必须同时清空旧`scoring`/`scoring_directions`并设置`scoring_replace=true`，
`scoring_mode=strategy`由源码固定ATR顺位，不让旧涨幅权重替代。
`s02_atr14.signals.json`同步已核实的30秒确认、涨幅0.8%～4%及早盘清仓参数；
按既有策略/信号保存接口使用，模板文件本身不会自动安装。
不得因安装示例而覆盖用户后续主动修改的受控设置。

当前完整池由每策略自身股票范围及状态选择形成，源码口径为`strategy_scope_v4`。
前交易日价格4～150元、换手1%～11%、涨幅0.5%～6%、流通市值50～500亿元
只用于预选；前交易日盘后生成并保存，买入仅从已保存名单内触发。
尾盘14:30启动、14:30:30确认，有效池成员上涨占比≥60%、涨幅0.8%～4%，
最近7个1分MA5、4个5分MA5严格递增；缺MA窗口仅跳过该股。
缺有效价格/昨收成员不进广度分母，完整池仍保留；全无有效成员待确认。
实时新买入计算和提交截止14:55:00，整点允许，超过拒绝；卖出及明确历史重算不受此限制。
源码返回全部合格命中。
次交易日相对精确未复权昨收±6%，10:30检查、10:45兜底，卖出不受排名限制。

排名公式为`mean(TR[T-14:T-1])/adjusted_close[T-1]`，其中
`TR=max(high-low, abs(high-previous_close), abs(low-previous_close))`。
使用连续15个完成交易日的一致复权日线，计算14个TR的简单均值；不是Wilder平滑。
同值按触发分钟相对准确未复权昨收的涨幅降序，再按代码升序。
`score`是该确定性顺位的编码；经济指标保存在`atr14`和`atr14_previous_close`，
参考日保存在`atr_reference_date`。当日或未来日线不参与计算。
预选按股计算并保存ATR；缺完整窗口保留资格、指标未知。
买入复用已保存ATR，不重复读取15根日K；ATR缺失仍保留信号并排末尾。
公共日历或整份证据不可读等错误沿现有失败语义处理。

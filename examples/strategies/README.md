# S02 ATR14/昨收分钟策略示例

`s02_atr14.py`可由现有`StrategyEngine`加载，使用独立示例ID
`s02_atr14_example`及`result_sections=signals`。该目录不在默认策略发现路径中，
发布不启用示例、不替换用户策略，也不改变运行配置或账户资金。

源码通过`app.strategy.market_data.previous_session(day)`读取已发布交易日历，
未知日期抛错，不以行情中最后一根日K代替准确前交易日。它不启动服务或连接数据源。
配套覆盖与信号JSON仅是示例；安装到独立私有目录时先核对ID冲突，不能覆盖用户设置。
配套覆盖清空`scoring`和`scoring_directions`并保存`scoring_replace=true`；
源码的`scoring_mode=strategy`固定ATR顺位，旧评分权重不能覆盖。

2026-11-08当前S02已取消20日均成交额≥1亿元条件，配套`overlay_filter=[]`；
成交额不足或缺失本身不影响预选、完整池及买入资格。通用因子和历史显式条件保留。
完整股票池采用`scope_only_v3`，只受股票范围与ST/停牌状态约束。
前日价格4～150元、换手1%～11%、涨幅0.5%～6%、流通市值50～500亿元只用于预选。
前交易日16:00保存资格；买入只消费已保存名单，返回全部合格命中，
资金和最多5仓等约束由交易模块执行，信号不等于成交。
配套信号14:30启动、30秒确认，涨幅0.8%～4%、有效池上涨占比≥60%，
最近7个1分MA5和4个5分MA5严格递增；缺MA窗口只跳过该股。
缺有效触发价或昨收的成员不计入广度分母，完整池保留；全无有效成员时等待。
实时新入场计算与提交固定14:55:00截止，整点允许，旧冻结容量窗口保持。
次交易日相对准确未复权昨收±6%，10:30清仓、10:45兜底。
这些模板值不自动保存至用户策略；安装或升级须保留用户后续主动修改的设置。

排名使用连续15个完成交易日的一致复权日线，计算14个
`TR=max(high-low, abs(high-previous_close), abs(low-previous_close))`的简单均值，
再除以准确T-1复权收盘价；不是Wilder平滑。同值按触发分钟相对准确未复权昨收的
涨幅降序、代码升序。`score`编码确定性顺位，经济指标保存在`atr14`与
`atr14_previous_close`，参考日保存在`atr_reference_date`。
当日/未来日线不参与计算。预选按股计算并保存ATR，坏窗口保留资格、指标未知；
买入复用已保存ATR，不再读取15根日K重算，未知ATR仍保留信号并排末尾。
未知日历或整份证据不可读继续遵守现有失败语义。

历史研究、生产归档及示例分别有独立身份，不能用示例测试认证历史收益。

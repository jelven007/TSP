# 策略源码示例

## S01 当前源码

[s01_signal_sections.py](s01_signal_sections.py) 是 `s01 / custom_mvxxcs01`
唯一自定义定义文件，维护基础过滤、候选投影、原始评分及执行能力声明。
保存参数、完整调用链、子计算异常和回归入口统一见
[S01 当前实现](../../docs/reference/s01.md)，本页不复制规则正文。
核对日期以唯一正文为准；文件修改不会自动安装或替换运行保存源码、覆盖及关联信号。
无冻结预选的适配路径及历史回归仍有调用，不能据当前单选信号删除兼容契约。

## S02 当前源码

`s02_atr14.py`、同名覆盖与信号JSON维护`s02 / custom_mvxxcp88`的一套当前定义，
由现有`StrategyEngine`加载。详细规则、参数、调用链和测试集中在
[S02当前说明](../../docs/reference/s02.md)，买任务子计算及异常在同页维护，
本页不重复保存时钟与阈值。
按既有策略／信号保存接口使用，文件本身不会自动安装或替换用户后续保存值；
历史研究仍消费各自冻结输入，不从本目录重新取得当前规则。
更新注释后源码摘要会变化；示例修改不证明两端运行保存源码已经同步。
S02源码的`RULES`仅指向唯一规则正文，函数注释描述自身输入、输出和责任。

## S03 当前源码

[s03.py](s03.py)是`s03 / custom_mvxxcs03`当前有效规则的唯一安装源。
规则、用户信号、调用链及测试见[S03当前实现](../../docs/reference/s03.md)；
通过现有保存接口安装对应租户，文件本身不自动改变运行策略。
关联信号的当前参数快照见[s03.signals.json](s03.signals.json)；
它供核对保存定义，后续用户保存值优先，文件本身不修改运行配置。

后续回测读取当前页面参数并冻结，统一交付要求见[AGENTS](../../AGENTS.md)。

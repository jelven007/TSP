# 历史镜像与缓存清理记录

日期：2026-10-31。本次范围为 TSP 的 GHCR 历史镜像、GitHub Actions 缓存、
本地项目缓存和已完成用途的镜像构建上下文。机器核验见
清理清单（附件保存在受控归档）。

## 实际处置

| 对象 | 结果 |
| --- | --- |
| GHCR `tsp` | 删除335个历史清单，345个降至10个 |
| TSP旧名称镜像包 | 逐版本删除164个清单，再删除仅余1个清单的退役镜像包；原165个清单全部退出可访问集合 |
| GitHub Actions缓存 | 删除428条，清理前API报告11,490,733,903字节，约11.49 GB；回读为0条 |

| 镜像构建上下文下载包 | 删除1份闲置归档，分配块2,764,800字节；本地合计约14.0 MiB |

GHCR清单数包含平台清单及证明清单，不等同于独立应用版本数。
远程镜像共享层的实际回收空间没有可核对的API数值，没有把镜像逻辑大小相加。
Actions数值为平台报告的缓存大小，不表示本机释放了11.49 GB。
本地分配块不保证等于整盘可用空间增量。

## 保留范围及删除依据

保留 `v0.4.39` 和 `v0.4.38` 两个版本，以及当前 `latest` 和提交标签。
每个版本保留顶层索引、amd64/arm64平台清单及两份证明清单，合计10个GHCR清单；
不能仅按是否存在标签来删除未标记的平台子清单。
保留清单均重新读取，内容哈希与清理前一致，两个版本的全部依赖仍可拉取。

旧名称镜像包虽然名称不同，其镜像提交和README属于当前TSP历史。
25个带提交标签的旧版本均通过Git祖先关系验证，当前运行和回滚入口使用新名称。
删除最后一个无标签清单时，GitHub版本API以公开下载量超过5000为由拒绝。
随后通过正常包删除API移除仅剩该历史清单的退役命名空间，
包元数据回读为404，旧 `latest` 无法拉取；旧 `tsp:v0.4.37` 也无法拉取。
此处理未改变保留版本的索引、平台清单或标签。

本地临时 `image-context` 已没有打开文件，内容为构建文件和前端静态资源，
不含运行数据或备份。对应下载归档也已删除。
两个登记在Git中的历史源码工作树分别含4项和11项未提交修改，予以保留。
缓存目录名称不能替代归属和活动状态检查。

没有清理运行数据、PostgreSQL、用户策略、备份、受控配置、当前依赖安装、
工具链或Git历史；没有提交、推送、发布或改动应用版本。

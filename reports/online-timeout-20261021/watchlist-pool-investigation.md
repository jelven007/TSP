- 同期 API 日志从记录生成到 Docker 收到的延迟最高为 47.755 秒。
  这是停顿线索，尚不足以单独判定为日志管道阻塞。

  内存使用约 5.4%。I/O wait 升高，而普通磁盘请求的平均延迟和利用率较低。
  十分钟统计不能定位具体瞬时等待。
- 05:25:01 再次观测到主机 I/O PSI：`some avg10=43.44`、
  `full avg10=43.29`。手工抓取阻塞线程时已恢复，不能虚构阻塞调用栈。

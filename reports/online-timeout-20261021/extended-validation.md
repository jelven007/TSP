## 并发口径与准入

使用一个现有管理员会话，同时维持 100、250、500 条 SSE 连接，叠加
40、80、120 请求/秒的 HTTP 请求。路由均匀覆盖市场总览、行情状态、
涨停梯队、自选、策略、能力及个人空间目录。除登录、一次性票据及退出外，
不写业务对象，不创建测试租户，不触发回测、通知或合成行情。
结果衡量该业务组合的连接承载能力，不代表 500 名独立多租户用户容量。

通过条件：

- 每档完整运行配置时长，实际 HTTP 请求量至少达到目标的 90%。
- HTTP 状态、响应契约及 SSE 均无错误，P95 ≤2 秒、P99 ≤5 秒。
- SSE 峰值连接数达到档位，累计连接时长达到目标的 90%，每条连接具备保活证据。
- 生产健康、容量余量及容器身份稳定；触发保护立即停止。
- 压测端事件循环最大延迟 ≤500 毫秒，跳过发送时隙 ≤5%。

REST、SSE、健康探针使用独立连接池；每个 SSE 池最多约 50 条长连接。
定速发送遇到落后时跳过错过的时隙，记录损失，不通过追赶突发增加生产负荷。

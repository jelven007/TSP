## 六项结果契约

| 页面/操作 | 当前实现 |
| --- | --- |
| 卖 | 默认隐藏买入信号日期；信号评分后依次显示现价、涨跌幅、换手率、量比、信号 |
| 选 | 默认隐藏数值参考日；选股评分后显示同样五列 |
| 买 | 分钟成交量显示整数，成交额显示整数与千分位；成交额后显示建议购买量/10万及实时五列 |
| 列表配置 | 对当前页保存显隐和排序；动态加载或渲染失败隔离在局部弹层，可关闭和重试 |
| 刷新 | 当前页按1000ms批量读取自己的证券；记录ID变化不重置用户选中的页签 |
| 布局 | 紧凑单元格；同字段采用共享固定列宽，允许表格内横向滚动 |

新增行情列读取当前北京时间日期的共享enriched缓存。现价使用未复权`raw_close`，
涨跌幅沿小数制、换手率沿enriched百分数制、量比沿`vol_ratio_5d`，
技术信号复用`getSignals`与既有14个技术字段。没有当日数据时显示“—”，
不使用历史触发价填充。行情日期与所查历史归档日期独立，不改写归档。
每秒是页面读取频率，数据到达频率仍由已有共享行情采集配置决定。

建议量单位为手，一手100股。公式为`floor(100000 / (raw_close * 100))`；
只在有限正价格下计算，缺失/零/负价显示未知。不含费用和滑点，不产生委托，
不修改账户资金或后续回测三资金要求。

页签选择绑定策略、查询日期和展示模式；批量持仓草稿继续绑定`record_id`，
防止使用旧记录的成交草稿。后台读取既有保存结果不运行策略；
实时快照扩展原`GET /api/screener/market-snapshot`，每批最多1000只，
只调用`get_enriched_latest(refresh=False)`，缓存冷时后台暖机；
旧全市场无参数调用保持原契约。没有Provider、数据库迁移或回测参数变更。

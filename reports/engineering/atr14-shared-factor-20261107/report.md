## 因子与兼容契约

| 项目 | 实际口径 |
| --- | --- |
| ID / 名称 | `atr14_sma_pct` / ATR14简单均值相对波动 |
| 分类 / 类型 | 波动率 / 内置虚拟因子 |
| 单位 | ratio；0.02表示2%，不乘100 |
| 公式 | TR=max(高−低, abs(高−前收), abs(低−前收))；最近14个TR简单均值 / 参考日收盘 |
| 日K参考 | 每日D计算截至D的窗口；D及前14个交易日共15根，同一复权尺度 |
| 分钟参考 | S02逐日调用已发布日历`previous_session`生成精确T-1的15日窗口；不会使用今日未完成日K |
| 缺值 | 不足15根、窗口缺根/重复、无效/非正/非有限价格、未知日历均不跨日填补；通用因子缺值，S02阻止扫描 |
| 旧因子 | `atr_14`继续递归平滑；`atr_pct`继续引用旧ATR，名称和定义不覆盖 |
| 目录 | 原77项及前48项挖掘顺序不变，新因子追加为第78项 |

唯一数值内核为[atr.py](../../../backend/app/factors/atr.py)。
[注册表](../../../backend/app/factors/registry.py)声明依赖和15根预热，
[评分物化](../../../backend/app/strategy/scoring.py)和
[NumPy矩阵](../../../backend/app/backtest/matrix.py)调用同一内核。
因子试算、检验和条件信号沿既有物化入口接入；未新建SQL schema或前端硬编码。
分钟源码从[受信任market_data入口](../../../backend/app/strategy/market_data.py)复用，
不扩大源码沙箱模块权限。15日窗口由调用源码从已发布日历逐日构造。

## 当前策略与参数

本次只移除重复ATR计算，并增加共享因子说明，当前两端保存源码SHA256相同：
`f1f2ef7d4df23d4b4b162fb1982c8f8df94c1639d7f1e13f3855bb722511de7a`。

- 完整池沿沪深主板、非ST/非停牌及流通市值50亿～500亿元形成，其他数值只筛选候选。
- 前交易日价格4～150元、换手1%～11%、涨幅0.5%～6%；20日均成交额≥1亿元。
- 尾盘14:30启动，分钟MA5计数7、5分钟MA5计数4、触发涨幅0.4%～4%、完整池上涨比例≥60%。
- 本地`evaluation_delay_minutes=1.5`，14:31:30确认；线上仍为1，14:31:00确认。
- 每只股票保留首次真实触发分钟，保留全部合格命中；ATR比率降序，同值按触发涨幅降序、代码升序。
- `atr_rank`从1起；`score`线性0～100，首名100、末名0、单只50。源码拥有评分，旧通用权重不能覆盖。
- 次交易日早盘清仓与排名无关；原最多5仓、T+1及成交/仓位约束沿执行模块，账户资金和其他参数未修改。

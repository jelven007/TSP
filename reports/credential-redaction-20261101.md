# 凭据脱敏与历史处置

公开源码不再内置管理员密码和注册口令。首次初始化从受控环境或运行
`.env` 获取 `AUTH_PASSWORD`、`AUTH_REGISTRATION_SECRET`；
普通管理员名称使用 `AUTH_USERNAME`，Windows 单机管理员沿用固定名称契约。
SMTP 凭据继续由运行配置提供。已有账户、后来修改的密码和注册口令不会被初始化覆盖。

本次变更同步了文档、环境模板、桌面验收登录和相关测试。
公开部署接受符合长度要求的受控初始化密码，不将它误认为源码默认值；
该行为不代表已暴露凭据自动失效，运行凭据轮换仍是单独的受控操作。

历史处置覆盖主分支、版本标签、压缩证据和提交说明中的确认泄露值，
保留提交拓扑和应用版本规则。历史提交 SHA 会改变；原始历史证据中的
SHA 和哈希继续表示原件，不能作为脱敏文件的校验值。
不可变的旧 Release 和涉密诊断附件需撤下。禁止从未处理的旧本地历史重新发布源码包。

验证：75 项初始化、改密保留、公开部署、通知和桌面检查通过；
62 项独立 PostgreSQL 账户与权限检查通过；前端登录检查和生产构建通过。
Ruff、文档结构、版本和差异格式检查通过。语义变化没有递增本地应用版本。
远程集成后版本仍由 CI 按现有规则递增。

GitHub 缓存提交、已关闭 PR 引用、他人克隆和仍运行的旧服务不因新提交而消失。
完成公开引用处理后仍须核对平台缓存，并在受控环境轮换仍有效的已暴露凭据。
原始备份仅用于受控恢复，不能重新公开。

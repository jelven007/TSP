## 实现与兼容

每个Full API进程启动5秒发布身份巡检，current不变时不下载大快照，
行情marker继续沿业务按需刷新。发布变化复用刷新锁，解码、仓库及Depth/Sector
准备放在短更新锁外，完成后提交。失败、停止、过时及超预算候选不能替换旧完整绑定。
就绪捕获同一绑定中的仓库、行情快照及租约，30秒宽限只适用于有效旧绑定；
持续失配、巡检超龄、入口或清单失效仍503。

只读不可变清单持共享锁，DataStore弱引用终结回调只保留独立连接和租约。
在途旧引用仍可查询，最后引用释放才关闭连接与锁；启动局部不再长期保留首个仓库。
维护标准库脚本持同文件非阻塞排他锁，重新核对current、近期及研究引用后删除；
锁忙/能力不可用跳过，研究查询失败仍终止。无flock平台保留读取兼容并禁用该删除路径。

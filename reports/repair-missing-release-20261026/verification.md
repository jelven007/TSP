## 需求与调用链

`FR-DATA-05` → `RepairDailyPanel` → `api.repairDaily` →
`/api/kline/repair_daily` → `run_repair_daily` →
`kline_gaps.sync_missing` → Provider或本地10分钟聚合 →
`persist_period(only_missing=True)` → 仓库视图/查询缓存/SSE → 任务卡。

可选mode缺省full，原全量盘后流程及自动完整性修复调用兼容。
missing按实际交易日、上市日期、证券及日期/分钟标签检测缺记录；
每100证券分块，仅连续缺失区间请求远程，写锁内再次排除已存在值。
10分钟只补具备完整十根本地1分钟的桶；日K只基于本地因子重算补入证券。
已有字段异常继续使用full。无缺口零请求成功，未知日历拒绝猜测，
部分补入保留数据并报告已补/剩余，取消不得继续写盘。
不新增数据集、扩展API、schema迁移或用户配置。

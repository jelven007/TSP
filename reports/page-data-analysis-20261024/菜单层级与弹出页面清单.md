# TSP 菜单层级与弹出页面清单

本文为 2026-10-24 的源码分析快照。当前位置及可移植入口见[分析索引](README.md)，后续实现与验证见[整合记录](../production-integration-20261024/verification.md)。

核对日期：2026-10-24。对象：当前 TSPP 工作区前端。按用户实际进入界面的层级，重新整理一级菜单、二级菜单、页内视图、弹窗、抽屉、浮层以及没有菜单入口的页面。

本清单根据实际路由、组件挂载、按钮回调和显示条件编写。工作区存在未提交修改，结论对应本次读取的实现。此次为源码入口核对，未重新完成全站浏览器操作或真实数据业务验收。

## 1. 层级与数量口径

| 层级 | 本文含义 | 例子 |
| --- | --- | --- |
| 一级菜单 | 应用主侧栏的页面入口；底部设置单独标注 | 行情、因子、回测、设置 |
| 侧栏二级菜单 | 在一级菜单下面展开的真实导航项 | 自选 → 全部 / 各自定义分组 |
| 页内二级视图 | 页面内部的标签、切换视图或纵向设置导航 | 因子 → 检验 / 因子库；设置 → 数据源 |
| 页内三级视图 | 二级视图继续下钻后的标签或嵌入面板 | 回测 → 验证 → 参数优化 / 步进优化 |
| 弹出页面 | 需要打开的业务弹窗或侧边抽屉，没有独立页面路由 | 策略配置、候选方案、批量创建账户 |
| 浮层 | 附着在按钮或字段上的菜单、帮助、选择器 | 加自选分组、封单提醒、日期选择 |
| 页内展开区 | 在原页面占据布局空间的表单、详情、说明 | 数据源编辑、通知渠道配置、异动规则口径 |
| 系统 / 隐藏 / 遗留 | 守卫流程、直接 URL 页面、关闭入口或失去调用方的模块 | 登录、首次向导、系统工具、旧 Analysis |

**当前为 18 个业务一级菜单，加底部 1 个设置入口。核心路由有 25 个可渲染页面定义和 6 个兼容重定向，共 31 个路径定义。**

动态分析页 `/analysis/:menuId` 只计一个路由模板；实际扩展菜单数量随配置变化。自选分组和共享弹窗也不能按实例重复累加为独立路由页面。本文不把普通下拉框、图表悬停提示和操作 Toast 计成独立业务页面。

入口事实源：[Layout](../../frontend/src/components/Layout.tsx#L85-L105)、[路由表](../../frontend/src/router.tsx#L148-L219)、[设置导航](../../frontend/src/pages/Settings.tsx#L36-L45)。

## 3. 逐菜单层级清单

### 01. 行情 `/`

没有固定二级菜单。首页是可配置组件网格，卡片和卡片内操作是功能区与分流入口。

| 层级 / 类型 | 页面或内容 | 从哪里进入 | 地址 / 条件 |

| 页内功能区 | 指数行情、大盘指标、涨跌分布 / 广度、情绪雷达、趋势强度 / 实用监控 | 首页组件 | 同一个 `/`；是否显示受布局配置影响 |
| 页内功能区 | 概念热度、行业热度、涨幅榜、跌幅榜、成交额榜、活跃换手、涨停梯队、监控中心 | 首页组件 | 同一个 `/` |
| 页内功能区 | 外部链接卡片 | 用户添加后显示 | 外部链接；可添加多个 |
| 间接路由入口 | 指数详情 | 核心四指数卡片 | `/indices?symbol=<指数代码>` |
| 业务弹窗 | 个股详情 | 股票榜单、梯队等组件的标的点击 | 共享 `StockPreviewDialog` |
| 业务弹窗 | 概念 / 行业成分详情 | 分类热度等组件的维度点击 | 共享 `DimensionMembersDialog` |
| 业务弹窗 | 欢迎首次使用 · 获取行情数据 | 首次取数引导 | 条件显示；可开始同步或进入设置 → 数据源 |
| 条件确认弹窗 | 当前无除权因子能力 | 首页获取数据的前置门控 | 共享 `useAdjFactorSyncGate` |

### 03. 自选 `/watchlist`

**唯一已经实现的业务侧栏二级结构是自选分组。** 在“管理自选分组”中开启“显示在侧边栏”，再展开自选菜单后，侧栏显示“全部”和各自定义分组；“未分组”在自选页面的分组栏中显示，侧栏没有单独列出它。

| 层级 / 类型 | 页面或内容 | 从哪里进入 | 地址 / 条件 |
| --- | --- | --- | --- |
| 侧栏二级 / 页内分组 | 全部 | 自选子菜单或页内分组栏 | `/watchlist`；也可 `?group=all` |
| 页内分组 | 未分组 | 自选页分组栏 | 页内选择；URL `?group=ungrouped` 也可初始化 / 切入 |
| 侧栏二级 / 页内分组 | 各自定义分组 | 子菜单或页内分组栏 | `/watchlist?group=<groupId>` |
| 页内二级视图 | 列表 / 卡片 | 顶部视图按钮 | 本地偏好；无专属 URL |
| 页内二级视图 | 分组卡片总览 | 顶部“分组卡片视图” | 临时整页模式；关闭 / 刷新回原视图 |
| 页内展开区 | 分组统计条、筛选条件 | 顶部统计 / 筛选按钮 | 内嵌，不是独立弹窗 |
| 业务弹窗 | 管理自选分组 | 分组栏右侧管理按钮 | 新建、改名、颜色、排序、删除；侧栏开关需 `settings:manage` |
| 业务弹窗 | 批量导入自选 | 顶部导入按钮 | 截图 / CSV / 粘贴代码；预览与导入目标分组在同一弹窗 |
| 侧边抽屉 | 自定义列 | 顶部“自定义列” | `ColumnCustomizer` |
| 业务弹窗 | 个股详情 / 成分详情 | 股票名称、图表、概念 / 行业标签 | 共享详情组件 |
| 确认弹窗 | 清空全部自选 / 清空当前分组 | 对应清空按钮 | 两个不同确认界面；清空分组仅在选定具体分组时显示 |
| 浮层 | 搜索结果、标的所属分组、加自选目标分组 | 搜索框或分组按钮 | 不属于新的二级页面 |

分组栏的点击由页内状态切换；侧栏链接则改变 URL。二者消费同一分组选择，不能据此把每个分组当成独立页面组件。

## 7. 入口组织的主要发现

1. **主侧栏以一级菜单为主。** 自选已经有真实侧栏二级分组；设置有独立的纵向二级导航，其余复杂业务主要依赖页内标签、功能区和弹窗。
2. **深链支持不一致。** 因子、回测、设置、自选分组、指数选择和监控部分入口可通过 URL 恢复；环境 / 异动 / 信号标签、模拟账户视图、财务详情标签主要由本地状态控制。
3. **弹出界面承担了完整业务流程。** 策略创建与配置、因子转策略 / 信号、候选复测、数据修正与批量账户创建都应在页面地图中保留父入口和嵌套关系。
4. **页内展开区需要单独标注。** 数据源编辑、扩展页面表单、Token 表单、通知渠道、单账户展开、财务详情和异动规则说明均有真实入口，但不是路由页或遮罩弹窗。
5. **无入口对象分属不同状态。** 指数是间接入口，登录 / 向导是流程入口，开发工具是刻意隐藏，视觉预览是直接 URL 试样，获取策略是关闭的未完成入口，旧 Analysis 才是确认的孤立模块。

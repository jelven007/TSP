## 本地最新组合

| 范围 | 当前契约与兼容边界 |
| --- | --- |
| 策略日期 | 北京时间交易日00:00后可选今天；默认日期、上限和新监控使用同日。历史手选保持，午夜切日不自动运行 |
| 账户偏好 | 策略池勾选采用账户／租户稳定键；退出、401、auth_version变化保留白名单偏好，私有查询／结果／草稿／任务ID仍清理 |
| 完整股票池 | 股票范围及流通市值约束构成完整池；其他数值和叠加只用于选股。08:00／09:00分别生成，09:00读取最新配置 |
| 股票池持久化 | 每策略每日仅保留最新成功池；保存与删除旧池同事务，失败保留旧池，迟到旧任务不恢复旧池 |
| 调度租约 | 不可用账户释放原租约，其他租户继续；失败按原分钟重试，不跨过两个整点边界 |
| 分钟扫描 | 直接与冻结任务均按策略传入最小剩余持仓；历史观察在所选日15:00，实时保留秒，空候选不吞截止出场 |
| 日线叠加与评分 | 通用分钟只用精确前交易日及更早已完成日K；20日均成交额不由分钟额替代，评分按实际触发价与原始昨收 |
| 独立卖／选／买 | 选是全部数值与叠加通过的完整集合，买保留真实触发点，卖引用同策略精确前交易日成功买入归档；缺数据分别标记 |
| 早盘收益账本 | A股通用分钟、单一早盘清仓、连续资金组合；精确T+1、单次滑点、分片累计费用及分钟量容量上界，缺数据／截止余股不输出完整净值 |
| 回测页面 | 等最新成功目录后恢复有效策略；空成功清理失效选择，网络失败保留。已选持仓出场可回显，能力限制对应实际后端 |
| 停复牌证据 | 小型独立事件文件，按已公开且已生效日期消费；缺文件兼容未知，缺行情不推断停牌，失败任务旧快照不改写 |

本轮升级保持用户已存策略、信号、交易、邮件及初始化配置，不用默认值覆盖显式参数。
默认早盘清仓为次交易日振幅6%或10:30截止，默认S02全天出场仍按其专用规则；
账户显式旧值继续生效。仓位、资金、费用和滑点沿各策略及回测输入，未统一替换。
扫描信号、回测模拟成交和真实委托是不同对象。

## 发布与升级门禁

1. 完整后端及临时PostgreSQL、前端测试／lint／build、工具、目录／文档／版本、
   增量Ruff和隔离HTTP验收，以新命令结果为准。
2. 完整暂存diff复审后提交，PR质量门通过才合并；CI自动递增并创建不可变源码标签。
3. 固定同一版本提交与OCI镜像，核对平台索引／镜像配置／构建文件清单。
   Compute从同身份Runtime构建并独立验证，原生本地环境用匹配源码／锁文件／静态页面。
4. 各端排空写入，备份控制／业务双库与受控配置，恢复临时库核对迁移、表计数和账本。
   当前两端均schema v7，原v1-v7字节校验和保持，不新增迁移。
5. 同步API／Platform／Gateway／四类Worker／Compute／前端；
   验证管理员登录、日期、勾选、历史、池API、真实Compute及完整重启。
6. 签收后删除已合入分支／过期工作目录，活跃源码／运行产物保留新版本及v0.4.42。
   不可变历史标签和Release作为审计点保留，用户业务备份独立保存。

手工发布及回退责任为本次授权执行代理，维护者接收脱敏回执。
若源／镜像身份变化、登录失败、账本／配置变化、健康失败或持续503，停止切换并恢复
已核验的原源／镜像／配置指针；出现不兼容新写入先保存增量，不直接恢复旧数据库丢弃数据。
本轮没有新增真实行情收益回测，不把历史研究或合成撮合样例称为本次五资金收益。
公共绑定6小时观察、完整交易日与持续容量仍按各自窗口签收，未结束不能标记通过。

# 源码诊断与预登记假设

本文件先于基准结果写入。基础过滤统一沿用系统默认；所有候选沿用原止损、
最长持仓、次日开盘、费用、资金及仓位，先改变入场质量，避免同时调多个主题。
若基础数据仍不满足严格研究要求，所有收益改善仅是探索性证据。

## 试验纪律与候选主题

先执行 22 个原版训练期和验证期基准，观察交易数量、亏损尾部、年度一致性、
自然退出与窗口末尾平仓差异。下列每一主题最多两个预定义候选，不扩展随机搜索。

1. **趋势质量（趋势跟随及放量突破，共9个）**：
   A=`ma20 >= ma60`；B=`ma60 >= ma60[5个有效交易日前]`。
   经济解释：排除中期下降中的短期反抽，代价是错过最早启动。
2. **回踩确认（3个趋势回踩）**：
   A=`close > close[1]`；B=`close > ma5`。
   经济解释：买承接确认，减少尚在向下运行的回落。两条件分别测试，不同时加入。
3. **超跌确认（5个超跌修复）**：
   A=`close > close[1]`；B=`close > ma5`。
   若与原逻辑矛盾而无交易，明确拒绝，不为制造交易悄悄放宽“新低”定义。
4. **避免过热（高换手拉升、强势高开、逼近涨停）**：
   A=`annual_vol_20d <= 0.6`；B=`annual_vol_20d <= 0.8`。
   检验更可控的波动是否改善扣费胜率，同时检查获利空间是否被削弱。
5. **涨停生态分开检验（2个）**：
   涨停基因 A=`close > ma20`，B=`close > close[1]`；
   连板股 A=原参数 `min_boards=2` 加 `consecutive_limit_ups <= 2`，
   B=加 `consecutive_limit_ups <= 3`。
   后者检验低位连板而非不断追更高板，但不将其命名为“一进二”。

每策略最多两个主候选。训练期不改善净胜率、期望、利润因子的候选不晋级；
验证期沿用 plan.md 门槛，同时要求交易数不少于原版50%。两轮均失败即停止。
通过者才做参数邻域、训练期按年/滚动稳定性与交易重采样诊断，随后封存
`finalists.json`（含原版）并一次性运行最终留出期。留出期失败保留原默认。

## 合并边界

- 六大族是交易意图分类；用真实信号 Jaccard/条件覆盖率、成交重合度判断重复。
- 优先将两套 RSI 超跌、两套 MA20 回踩的共同计算归并；保留参数单位差异
  （回踩偏离度分别为0.02和2.0）、退出规则、评分、资产类型和原 ID。
- 未出现高度重复证据时不强制删除变体，也不把多个相关策略当成独立分散投资。
- 分类与共同实现整理不计为赢单率提升；参数采纳必须另有样本外证据。

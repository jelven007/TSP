# TSP 22个策略优化方案 · 第一版

日期：2026-10-19

源码核对基线：`c5583f4b93e15a286583e406fbd32ab521792cb1`（应用 v0.4.9）

性质：研究与开发方案；本次没有修改策略、运行新一轮绩效回测或调整账户。

## 1. 核心判断

**建议把22个策略从“技术形态筛选＋通用交易规则”，逐步优化为有适用行情、明确触发、可成交约束、独立退出和样本外证据的交易系统。首先提高交易质量，再考虑增加交易次数。**

胜率无法保证。本方案把“提高胜率”落实为可验收的目标：在相同数据、费用和风险预算下，提高扣费后的盈利交易比例，同时保持正期望、控制回撤，避免靠扩大止损、过早止盈或压缩到少数样本制造高胜率。未经验证的参数均为研究起点，不是已知最优值。

建议采用以下顺序：

1. **先校准证据。** 核对历史回测、成交与指标口径。严重亏损既可能来自交易逻辑，也可能受数据与模拟方式影响，不能全部归因于买点。
2. **优先研究六项。** 新低反转、长下影反击、超跌反转、MACD零下回升、均线回踩反弹、平台整理突破。前四项有相对较好的旧样本线索，后两项有清晰可检验的结构假设；这不是盈利排名。
3. **其余策略分批优化。** 趋势与突破类重点检验首次触发、入场位置和退出；强势与涨停类重点检验可成交性和情绪环境。
4. **保留22个公开ID，按证据决定用途。** 合格者进入模拟观察；不合格者保留为观察或辅助过滤。全面评估不等于要求22个全部独立交易。

### 2.3 优先处理的口径与能力缺口

1. **统计命名。** 当前回测引擎旧 `profit_factor` 字段计算平均盈利/平均亏损，即盈亏比；研究CSV另行计算的是金额PF。新增明确字段并兼容旧API，排行榜不能继续混用。
2. **开盘封板成交。** 当前日线开盘路径主要拦全天一字板；“开盘涨停、稍后开板”不能凭全天OHLC证明开盘买得到。卖出侧亦需验证开盘跌停、稍后打开的情形。优先补原始开盘限价检查；有分钟证据时才允许按后续时刻重试，禁止回填为开盘价。
3. **基础价格和市值。** 基础过滤源码用 `close` 及 `close × shares`，而enriched价格为前复权。历史绝对价格、市值过滤应核对并改为当日原始价及当时可用股本；收益/趋势指标继续使用一致的复权序列。此属口径修正，需要重建公平基准，不计作选股能力提升。
4. **评分缺失。** 矩阵评分对缺有效因子的候选可给0分，未必同时移除入场资格。应区分“不可计算”和“真实低分”，缺关键输入时不允许进入交易排序。
5. **滚动验证。** `generate_folds` 当前用 `timedelta`，`train_days=252`实际是252个自然日；未提供完整的持仓跨边界清理与重叠测试窗治理。不能把当前默认值描述成“一年交易日训练＋一季度交易日验证”。
6. **环境阈值的研究历史。** 环境计算源码注明用2022—2026年分位数校准。T−1只解决数据时间对齐，不能消除阈值曾看过未来样本的问题。旧窗口分组只能作探索性归因；正式新试验需冻结现有阈值向前验证，或在每个训练窗内重新校准。
7. **未实现的交易政策。** 每笔入场ATR/结构位冻结、按风险金额配仓、跨策略行业额度和完整竞价队列均不是已有通用插件接口。先按真实用例小范围扩展，不能假定文档中的 `PositionSizingPolicy`、`BacktestCostModel` 等目标接口可导入。

## 3. 目标与统一评估口径

### 3.1 采用三组指标

| 指标组 | 必须输出 | 作用 |
| --- | --- | --- |
| 信号质量 | 命中数、首次触发数、可成交数、拒单原因、分组后续收益 | 判断形态是否具有信息、是否买得到 |
| 单笔交易 | 净胜率、平均盈利/平均亏损、净期望、金额PF、持有期、MAE/MFE、最差尾部 | 区分买点、退出和成本问题 |
| 账户表现 | 净收益、日度净值、最大回撤、平均/峰值敞口、换手、费用、基准超额 | 判断优势能否落实到资金路径 |

统一定义：

- 净胜率＝净盈亏严格大于0的已平仓交易数÷全部已平仓交易数。零收益计入分母；未平仓另列，不能隐藏亏损浮仓。
- 金额PF＝盈利交易净盈利金额总和÷亏损交易净亏损金额绝对值总和。
- 盈亏比＝平均盈利交易收益率÷平均亏损交易收益率绝对值。
- 净期望＝逐笔净收益率均值；账户收益按实际资金路径计算，不能用净期望乘笔数替代。
- 同时报告自然退出与窗口末尾退出；亏损到期仓、停牌待卖仓和失败试验都保留。
- MAE/MFE为持仓期间最大不利/有利波动；只用于事后诊断，不能反向决定当时的止损。

例：胜率45%、平均盈利8%、平均亏损4%时，费前单笔期望为1.4%；胜率70%、平均盈利2%、平均亏损8%时为−1%。因此不能给全部22个策略统一设置“必须70%胜率”。

### 3.2 建议的两级门槛

下面是本方案提出的管理门槛，需在实验前冻结，不是行业通用标准或收益承诺。

| 阶段 | 门槛 |
| --- | --- |
| 候选进入深入验证 | 相同输入和资金约束下，训练/验证净期望不下降；若主张提高胜率，净胜率点估计提升至少3个百分点，且PF、账户收益不恶化；交易数不足基准50%时需单独说明覆盖变化 |
| 进入前瞻模拟观察 | 主要样本外窗口合计至少200笔已平仓、跨至少12个月；基准成本下净期望>0、PF≥1.20；账户净收益>0；在预定仓位下最大回撤≤20%；至少三分之二非重叠样本外窗口净收益为正 |
| 成本与统计补充条件 | 滑点升至单边20bp后仍有正净期望且PF>1；按时间块重采样的净期望95%区间下界>0。若声称“胜率提升已验证”，提升差异的区间也需排除0，并考虑多重尝试 |
| 证据不足 | 未达笔数、区间跨0或历史输入未合格，标记“证据不足/探索观察”；不靠放宽条件自动晋级 |

20%回撤门槛用于第7节建议的账户风险预算，不拿旧100%敞口回测直接比较。历史已被使用的样本无法提供新的独立性；即便滚动诊断达标，仍需冻结后前瞻观察。

可以接纳“胜率相近但正期望和回撤显著改善”的策略，但应称为风险收益改进，不能记作胜率优化成功。

## 4. 所有策略共用的改造

### 4.1 数据与可交易股票池

- 保持沪主板、深主板、创业板、科创板四板范围；当日股票池必须有效，不用demo或当前在市列表替代历史完整池。
- 当前公共过滤为价格3—300元、总市值至少10亿元、当日成交额至少2,000万元、排除ST和上市不足30自然日。`exclude_new_days`是自然日年龄，技术指标窗口及持有期按交易日，二者不能混写。
- 初轮仅作流动性分层：过去20个有效交易日成交额中位数低于5,000万、5,000万—2亿、2亿以上。检查各层净期望和冲击，之后才决定是否把5,000万元设为新下限。
- 证券状态、股本、财务及行业成分均按当时可得信息；缺失标记保留。若没有历史行业成分，先做不依赖行业的方案，不能用今天的“热门板块”回填历史。
- 技术指标统一使用既有复权定义。涨跌停、竞价缺口、成交价格、容量和市值使用原始价及历史制度；跨除权日同时核对现金/股数变化，避免复权收益与现金分红重复计入。
- provider沿用rustdx默认、tickflow可选和现有能力矩阵。缺分钟、盘口或历史证券数据就停止该项正式验收，不静默换源填数。

### 4.2 市场状态先归因，再过滤

先复用五级环境 `strong / lean_strong / range / lean_weak / weak`。状态与数值阈值都作为固定研究配置留档。

| 环境 | 候选使用方向 | 建议账户总敞口上限 |
| --- | --- | ---: |
| 强势、偏强 | 趋势、平台突破、趋势回踩；强势延续需另过成交门 | 60% |
| 震荡 | 优先回踩与有确认的超跌修复；减少追突破 | 40% |
| 偏弱 | 仅已验证的修复模型，先观察其尾部损失 | 20% |
| 弱势或数据未知 | 停止新开仓，继续处理存量退出 | 0% |

这是待验证的配置，不是自动启用建议。对“弱转强”类模型，定义必须由截至决策时已经发生的状态转移构成，不能根据后来反弹给低点补标签。

现有 `regime_filter` 按信号日期T使用T−1环境，随后还有入场延迟；正式复现保留这条链。若研究“收盘T环境决定T+1开盘”的版本，单独变更对齐契约并补测试，不能手工少移或多移一日。

### 4.3 将状态变为事件

为持续型条件定义“本次形态周期”：未成立→成立→首次确认→失效/退出。优先检验首次触发、形态失效后重置、退出后冷却3或5个交易日两个候选。

已有回测会拦持仓中重复买入和同日卖出后重入；本项解决的是**退出后同一持续状态反复开仓**，不能把已有能力重复算成新增功能。形态冷却也不等于通知冷却。

### 4.4 排序先验证方向，再调权重

现有策略大多用候选集内min-max归一化，偏好更大涨幅、量比、动量或换手。分数只是相对排序，**80分不是80%盈利概率**。

建议按以下顺序试验，每次只改一层：

1. 固定信号、退出与仓位，比较原排序和单一候选排序；按入场评分五分位检验净期望是否单调。
2. 用等权入选作为诊断对照，识别损失来自形态还是排序。随机排序仅用固定种子分布作对照，不挑最好的一次。
3. 对极值敏感的因子比较百分位排名与原min-max；缩尾阈值从训练集确定，缺值不能填0伪装为可交易评分。
4. 趋势重视相对强度与入场偏离，修复重视收盘位置与止跌强度，强势重视承接与成交条件。换手、量比通常先检验区间偏好，不假设越大越好。
5. 仅在单项有证据后组合最多3个互补评分因素；禁止一次优化十几个权重。

已有因子归因是盈利/亏损交易的入场因子均值对比，不是因果归因。六族、行业、市场状态、退出原因和MAE/MFE分析需补充；矩阵路径归因输出的覆盖范围还须单独验收。

## 5. 22项逐一优化

记号：C/O/H/L为同口径日K收盘/开盘/最高/最低；VR为今日量÷此前5个有效交易日均量；CLV＝(C−L)/(H−L)，零振幅或缺价视为不可计算；ATR为既有14期定义。

各项“先验候选”先独立检验，**不把全部建议条件一次叠上**。当前默认止损以损失幅度表示，实际损失可能因T+1、跳空和跌停超出该幅度。每日收盘确认的候选，默认下一交易日开盘执行；需要盘中确认的候选另走有完整覆盖的分钟回放。

## 6. 新低反转与一进二的重点设计

### 6.1 新低反转：两条研究线并行记账，结果不拼接

保留现有低开收阳模型作为A线，只改变一个承接质量条件；B线是“出现极端下跌形态后，等待后续确认”的新定义。

```mermaid
flowchart LR
    A["T日收盘：原新低条件成立"] --> B["冻结T日高低点、ATR及数据版本"]
    B --> C{"随后1至3个交易日"}
    C -->|"跌破冻结低点或超时"| D["观察失效"]
    C -->|"收盘突破冻结高点"| E["确认成立"]
    E --> F["下一交易日：检查资格、限价及容量"]
    F --> G["可成交才建仓，保存退出政策"]
```

对每个观察周期最多一笔新仓。确认日与观察日各有时间戳；停牌期间观察有效期按市场交易日推进，不能无限等到复牌上涨后再成交。ATR取已完成信号日数据，跨除权时对冻结参考位作有记录的一致调整。

必须输出新低反转专项归因：

- 按入场年/月、五级环境、四板、流动性、开盘缺口分组的净期望和账户贡献。
- 2025年与其余年份分别报告；前5只股票、前5个月的利润贡献及剔除敏感性。
- 形态日到实际成交的缺口损益；止损、时间退出、MA20退出的笔数和金额。
- 原版、承接筛选、延后确认各自的漏掉盈利、避免亏损及新增交易，不只看留下来的样本。
- 去掉2025年的诊断不能重新命名为独立样本外；它只能揭示集中度。

### 6.2 一进二：先用连续竞价承接版本验证

首个可实现研究版本优先选择“T−1首板池→T日开盘后5分钟承接确认→下一分钟下单”，数据要求低于完整集合竞价排队，且决策时点更清楚。

1. T−1收盘后冻结首板池；按原始价格、当日涨停制度判断首板，排除无价格限制日。
2. T日只用9:35前已完成数据，观察开盘缺口、已成交金额、VWAP及回落承接；初始缺口分层研究，不凭经验直接宣称2%—5%最优。
3. 订单设置到达延迟、限价、有效期及成交参与率；没有后续可见成交容量记未成交，不能删掉未成交样本。
4. 首次买入日不能卖出；模拟次日低开、一字跌停、连续停牌及待卖重试。
5. 秒级预开盘归档可支持观察，但当前 `second_execution` 仅接受连续竞价时段，不能拿它验证09:15—09:25集合竞价成交。真正竞价版另补撮合与数据契约。

当前“四板股票池”指四个交易板块，与“四连板”完全不同；一进二池也不得附加无关四连板约束。

## 7. 退出、仓位与组合优化

### 7.1 退出先做贡献诊断

同一入场集合先对照原退出，明确盈利交易是否被截短、亏损交易是否缺少失效条件。再按策略族预登记退出候选：

| 类型 | 重点比较 | 不允许的做法 |
| --- | --- | --- |
| 趋势 | 结构保护、MA20/MA10退出、20—40日时间上限 | 为回本无限延长持有 |
| 突破/回踩 | 冻结突破位/回踩低点失守，3—5日无进展退出候选 | 每天下调原支撑位放大止损 |
| 超跌修复 | 修复到MA20/RSI中轴、5—15日时间退出、结构失败 | 用过小止盈和过大止损制造胜率 |
| 强势/接力 | 1—5日持有、承接失败、断板后的退出意图 | 假设新买股票可当日卖出或跌停必能成交 |

先沿用固定5%—8%止损做入场比较；后续独立研究入场ATR止损，候选倍数为1.5和2.0。结构位对应风险过大时弃单，不把结构位随意拉近。ATR止损与固定止损是竞争政策，不能结果出来后选择每笔更有利的一条。

结构位、入场ATR、时间止损中的“无进展”和分批止盈需要持仓上下文。当前 `compute_signals` 和标量 `RiskPolicy` 不自动提供这些语义，必须先开发并验证；分批止盈放在后续阶段，避免首轮增加额外路径歧义。

日线同根触及止损/止盈时沿用已存在的保护优先假设，并做分钟样本核验；跳空按实际可成交价，T+1和无法退出继续保留。固定6%止损不是最大损失6%的保证。

### 7.2 建议模拟观察风险预算

- 单笔计划风险先取账户权益0.3%，硬上限0.5%；单股名义仓位上限10%。
- 总仓位按第4.2节环境上限，最多8只；同一行业上限20%，同一强相关策略组上限30%，均以账户权益为分母。
- 涨停/高开/高换手策略合计名义敞口暂不超过10%，直至成交与尾部压力验收通过。
- 亏损仓不因重复信号自动加仓；手工仓、待买单、已买未结算数量一并计额度。
- 单日账户损失达到1.5%时暂停新增仓位；净值自高点回撤8%时减半新风险额度，12%时停止新开仓并复核。存量持仓继续按可成交条件退出。

上述数值是研究账户初始预算，不代表用户个人资产配置；风控触发也无法阻止跳空穿越阈值。

拟新增风险仓位公式：

`数量 = 按板块最小申报单位向下取整[min(权益×风险预算÷每股压力损失, 单股额度÷原始入场价, 可成交容量, 可用资金约束)]`

每股压力损失包含计划止损距离与费用/跳空缓冲；先验证精确板块规则。当前日线回测按100股取整，不能认为已经完整支持科创板全部申报数量要求。股数过小、最低佣金侵蚀明显时弃单并记录。

现有等权、评分配仓和模拟盘仓位上限可先复用；风险金额配仓、行业/相关组额度及账户回撤联动属于待开发政策。

### 7.3 去重和风险归属

同股、同方向、同一形态周期只产生一个账户决策，记录全部命中策略，并选择事先定义的主策略负责退出。信号多不能自动叠加仓位或解释成更高成功率。

同时计算信号Jaccard、同股同买入日成交重合和日度收益相关性。高度重合策略合并额度；互相冲突的退出按入场政策快照处理。现有叠加策略是信号合并，不能替代完整组合风险预算。

## 8. 成交与成本验收

### 8.1 三套对照

| 场景 | 费用与执行 | 用途 |
| --- | --- | --- |
| 旧基准复现 | 原佣金、5bp滑点、历史印花税、原成交模型 | 对齐旧报告，定位差异 |
| 新公平基准 | 原始价格、实际费率及最低佣金、适用过户等费用、加强涨跌停/股数校验 | 所有新旧策略在同一新模型重测 |
| 压力场景 | 单边滑点10/20/50bp；延迟、部分成交、订单过期、低流动性和连续跌停 | 判断优势是否仅存在于理想成交 |

最低佣金与费用包含关系按实际券商费表确认，避免规费重复计算。当前日线模型主要按比例计费；秒级执行模块已包含最低佣金，但不能据此称全部回测路径都有。

对非开盘集合竞价订单，建议比较0.5%和1%的可观察成交参与率；过去20日成交额只用于预先估计容量，实际成交不使用当日未来完整成交量。在100万、500万、1,000万元研究资金规模下比较容量退化，不外推为无限可扩容。

### 8.2 时间与交易制度

- 每笔记录形态时刻、信号可用时刻、订单到达时刻、首次可成交时刻和实际成交原因；信号使用T收盘后，不能回到T开盘成交。
- 日线策略下一交易日订单默认当日有效；因停牌、无量、涨跌停未成交后，不无限延续陈旧买单。后续重试需要仍在有效窗口及新资格复核。
- 涨跌停价按当日原始参考价、最小价位及历史规则计算；上市无价格限制期独立处理。
- 主板ST涨跌幅在2026-07-06由5%改10%的日期切换已在项目实现，本轮只复核，不重复建设。依据见第11节。
- 买卖最小数量、T+1、停复牌、除权、零股卖出分别验证；不能把ETF规则套给股票。本方案业绩研究仅针对A股，已有ETF能力做兼容回归，不混合统计。
- 缺分钟数据时既有日线降级只可保留为探索性结果；正式“分钟成交已验证”要求完整覆盖及明确拒绝缺口。

## 9. 防过拟合的研究流程

### 9.1 先冻结两条基准

**复现基准**：旧数据快照＋旧代码/参数，核对报告聚合指标及随机抽取的交易；无法取得完整旧输入时注明“不可精确复现”，不能假装相同。

**当前基准**：当前代码＋冻结的新输入，在不改变22个入场规则的前提下运行。每项数据、成本和成交修正都同时作用于旧策略和候选，先解释基准变化，再计算优化增量。

对严重亏损策略，每族至少抽查5笔，覆盖盈利、亏损、跳空、涨跌停和窗口尾部；从信号到仓位、手续费、T+1及净值手工核算。报告再现不代表经济假设已验证，但可先排除基础算账错误。

### 9.2 时间拆分

1. 2021-10-18至2026-10-16已研究数据用于诊断与开发，不再封成“全新留出”。旧结果必须连同失败候选进入试验台账。
2. 建议滚动训练504个交易日、验证126个交易日、步长126个交易日；用真实交易日历生成明确起止日期，不直接把这些数填入当前自然日实现。
3. 清除训练中收益标签或持仓结果跨入验证期的样本；固定持有期标签按其终止时刻清理。停牌导致期限延长的按实际结果可得时间处理，不能只机械留30天。
4. 若采用保守固定隔离带，以30个交易日作为初始值，并核对最长有效结果期限；策略指标预热可以使用验证期以前历史，但不能把验证收益用于训练。
5. 不重叠的样本外窗口按实际日期拼接；重叠窗口只用于诊断，不重复复利。跨窗持仓、窗口末尾清仓及参数切换分别明确，最终另跑一次真实连续组合。
6. 参数和代码冻结后的下一个完整交易日开始前瞻观察；方案日当天已发生数据不自动算前瞻。若中途改模型，该模型观察起点重新登记。

### 9.3 有预算的实验，不穷举参数

- 每策略首轮最多2个有经济解释的候选，首批6项最多12个；剩余16项第二批最多32个。原基准不计作新候选，但结果完整保留。
- 顺序为信号定义→排序→退出→仓位→组合。每阶段先冻结上一阶段；新增退出/仓位主题也计入累计试验次数，不能藏在“工程调整”里。
- 邻域只检验已晋级参数两侧，不用验证期挑最优邻居。连续两轮同主题无改善即停止，最多8轮强制复盘。
- 交易按信号月份/时间块重采样，保留同日股票共振和持有期相关性；不能把数千笔同市场交易当成完全独立样本。报告块长敏感性。
- 除本轮候选，还计入上轮44个主尝试和实际邻域等后续尝试；无法重建的研究历史记为未知，不把次数归零。
- 已有DSR仅对当前网格的Sharpe目标提供独立试验近似，不覆盖22策略跨轮选择。整体选择可用联合时间块重采样的最大统计量或预登记的多重比较校正；BH-FDR函数可辅助探索，不能替代时间独立验证。
- 报告因子、市场状态及板块归因时，保留未显著和失败分组。对跨许多切片挑出的“有效市场”，必须作为下一轮新假设重新验证。

## 10. 开发与交付安排

本方案不预设需要一套新平台。配置能够表达的归为L1；核心数据、成交或持仓政策变化属于L3，复用已有模块作最小接线。当前纯价格 `RiskPolicy` 已存在，但它不是可任意注册替换的完整风险插件框架。

| 工作包 | 改动范围 | 验收产物 |
| --- | --- | --- |
| A：基准与口径 | 指标字段、原始价市值、缺评分输入、费用、开盘限价/申报数量；冻结输入 | 22策略当前基准、旧结果差异解释、逐笔核算证据 |
| B：六项首批实验 | 第08、11、13、15、16、17项；先分别检验入场，后评估退出 | 每项最多2个候选、失败理由、分期净值、完整信号与成交差异 |
| C：其余16项 | 趋势首次触发、评分方向、回踩确认；强势/涨停仅在执行门通过后升级 | 全部22项“保留/观察/改进候选/停止主题”的判定 |
| D：持仓与组合 | 冻结结构位/ATR、风险配仓、同股去重、行业/相关组额度 | 回测/模拟盘政策一致性、跳空与连续跌停压力报告 |
| E：验证与观察 | 交易日折分、跨边界清理、试验台账、冻结后影子模拟 | 样本外报告、每日拒单/成交差异、观察满期后晋级结论 |

工作包A是B/C绩效解释的前置条件。可以先写形态数值测试，但不得在口径尚未统一时把候选收益与旧表直接比较。

建议人日量级：A为5—8人日，首批B为5—8人日，C/D为8—15人日；数据补齐、真实成交样本积累和外部资源另计。前瞻模拟至少60个交易日且至少100笔已平仓，用于运行一致性检查；达不到第3节统计门槛时继续标记证据不足。观察期不能用加速历史回放替代。

结合当前M4/16GB开发机，绩效研究采用单个重计算任务、共享不可变矩阵和有界缓存；先小样本验证契约，再全市场顺序跑。避免同时执行全量容器构建、多个大回测和另一个项目的重任务。现有优化器单worker串行能力可直接复用。

### 10.1 每个策略必须交付的证据卡

| 内容 | 要求 |
| --- | --- |
| 身份 | 策略ID、源码哈希、完整参数及override、规则定义版本 |
| 输入 | provider、数据发布与快照哈希、交易日历、历史池覆盖、未知状态比例、费用版本 |
| 假设 | 为什么可能有效，具体改哪一个主题，哪些旧失败试验相关 |

### 10.2 最小充分验证

- **策略数值**：逐项正例、反例、临界值；无量、缺值、停牌、同根入退冲突；新低两阶段时序、历史低点确认延迟、粘合/回踩重置。
- **执行**：信号后次日开盘、T+1、开盘封板后打开、跳空穿止损、跌停待卖、买单过期、最低佣金、科创板申报数量及除权参考位。
- **历史**：ST变更、上市日期、退市输入缺口、首次采集前未知状态；缺严格PIT数据继续拦截，不通过修改标志放行。
- **验证框架**：交易日折分、相邻窗不泄露、重叠窗不重复记收益、共享矩阵覆盖完整预热、跨窗口持仓和尾部退出。
- **一致性**：同一输入与政策下选股、回测、监控和模拟盘候选排序一致；策略override修改后配置、实例、结果缓存、监控与前端失效链完整。
- **工程交付**：执行受影响模块测试、Ruff及`git diff --check`；有API字段变化同步前端类型，有前端变更再构建。纯方案阶段不运行全量生产回测冒充策略验收。

优先复用现有[策略家族测试](../../backend/tests/test_builtin_strategy_families.py)、[矩阵策略测试](../../backend/tests/backtest/test_matrix_strategy.py)、[回测正确性测试](../../backend/tests/backtest/test_strategy_backtest_correctness.py)、[费用测试](../../backend/tests/backtest/test_cost_model.py)、[滚动测试](../../backend/tests/backtest/test_walkforward.py)、[秒级执行测试](../../backend/tests/backtest/test_second_execution.py)。

### 10.3 兼容、上线与回退

保留旧ID、参数单位及旧结果的定义版本；新候选不自动覆盖用户override。形态定义变化必须可追溯，不能给旧回测换一个名字。

参数采纳后按原链路更新持久化、运行实例、结果缓存和监控；正在持有的仓位沿用入场政策快照，不能因新版本改掉原止损。新增字段为旧配置提供明确默认，旧仓无必要快照时不得猜造参考位。

先影子观察，再做上线决策。回退停止新增仓位并恢复前一套已冻结规则，存量退出意图继续履行。应用版本仍由远程集成到main后的CI递增；本地实验与方案不手动改号。

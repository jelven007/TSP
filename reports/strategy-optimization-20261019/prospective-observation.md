# 冻结后观察登记与操作规程

状态：规程已准备，观察尚未启动；没有创建生产自动下单规则或定时任务。
本文件不是应用可直接导入的配置。策略参数使用现有策略设置与回测入口；
未实现的账户联动规则不能靠填写本文件生效。

## 观察对象与冻结

22个公开策略保留原ID及原参数。19项策略的31个形态候选、20个执行/风险候选
均保留为登记过的研究主题；最终历史判定见同目录研究结论与逐策略证据卡。
失败主题不重复搜索参数，不根据观察途中收益临时切换候选。

观察开始前记录以下事实，缺一项不计为正式观察：

| 项目 | 要记录的事实 |
| --- | --- |
| 代码 | 实际部署commit、执行/费用版本、策略定义哈希；本地开发分支不能冒充已部署版本 |
| 参数 | 每个策略完整参数、override、持有/退出政策；候选值不能只留中文名称 |
| 数据 | provider路由、每日行情release、证券状态/股本覆盖、交易日和完整性检查 |
| 时间 | 完成部署与冻结的北京时间；起点为之后的下一个完整交易日 |
| 运行方式 | 信号影子记录，不向真实账户发单；是否另开模拟账户必须单独标明 |
| 费用 | 佣金、最低佣金、额外费用是否已含规费、滑点，不能用研究假设代替券商费表 |

2021-10-18至2026-10-16已看过的历史用于开发诊断。方案日当天及冻结前已发生
的市场数据不补记为前瞻；中途改动影响信号/执行的规则，该模型重新登记起点。

## 每日工作

1. 收盘后保存各模型的信号证券、信号时间、价格尺度、评分、数据版本和配置哈希。
   持续状态、首次触发和延后确认分别计数；没有信号也保留当日记录。
2. 下一交易日逐笔核对拟成交时点、原始价格、风险参考、限价和证券资格。
   买不到的订单保留原因，不删掉涨停、停牌、缺数据或风险额度拒单。
3. 持有期间保存入场政策、冻结保护位、风险退出意图与T+1/跌停待卖。
   更新候选参数不能改写已有仓位的退出依据。
4. 每日勾稽现金、持仓市值、已实现与未实现盈亏；核对同日资金和仓位的阶段顺序。
   系统重启后复核冻结保护位和未成交意图仍然存在。
5. 每周固定汇总一次：覆盖率、拒单率、净胜率、净期望、金额PF、敞口、
   回撤、成本和模拟/观察成交差异。保留无交易、失败与未平仓样本。

22策略先做信号影子记录。共同资金账户不能通过相加22条独立净值构造；
需要模拟组合时复用现有单股去重、待买额度占用和总敞口限制，
先确定唯一主策略负责每笔持仓退出。

## 风险能力与尚未启用的约束

当前可用：成交溢价上限、确认信号日ATR/低点冻结、按权益比例缩减计划风险数量、
现有单股/总敞口/持仓数限制。模拟盘使用这些入场风险政策时必须启用跟随策略风控；
原始股数和回测等价复权单位不同，模拟盘科创板申报规则尚未完整校准。

单笔计划风险0.3%—0.5%、单股10%、最多8仓等只作为后续模拟账户预算起点，
不能据此认定实际损失有硬上限。当前风险公式不包含费用和跳空缓冲。

以下项目不作为已实现功能填写或验收：按历史行业/相关策略组自动分配额度、
账户日损和回撤自动降档、完整分钟账户事件与竞价队列、真实冲击容量、
没有历史指数支撑的市场状态归因。需要它们时先补实现/数据，再登记独立实验。
缺少这些能力时保持信号观察，不声称已完成全自动组合风控。

## 满期与停止条件

至少60个真实交易日、至少100笔已平仓，只说明可以评估运行一致性，
不等于验证统计优势。停牌未退出、期末持仓和未成交订单仍留在统计。
历史绩效的多重尝试不能通过重新开始观察而清零。

晋级仍依原方案：至少200笔跨12个月的合格样本外交易、净期望>0、
金额PF≥1.20、正账户收益、适用风险预算下最大回撤≤20%，并通过成本和
时间块区间检验。声称胜率提升还需差异区间排除0及跨主题选择校正。
60日届满但证据不足时继续标注不足，不下调门槛。

若发生时间倒置、数据版本混用、现金无法勾稽、冻结参考缺失、
限价或T+1绕过，暂停该模型新增模拟仓，保留存量退出与全部日志。
修复后从新的代码/数据冻结登记重新开始；不能删掉故障日期维持漂亮指标。

回退前先停止新开仓，保留入场政策与退出意图，再恢复上一套已冻结实现。
本轮没有覆盖用户账户、原回测记录或正在运行的验收环境。

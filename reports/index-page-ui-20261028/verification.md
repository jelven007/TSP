# 指数页任务与K线控制修复验证

日期：2026-10-28。基线：`1c630cc2` / v0.4.36。
本轮未改版本、未提交、未推送、未部署，也未触发真实数据修正任务。

## 修复范围

- 数据修正任务进入成功、失败、取消或中断终态后，先刷新指数/任务查询，
  保留结果5秒，再自动收起当前任务卡片。
- K线默认60根；放大/缩小以图表实际回报的有效根数为上限、最少1根。
- 数量文本移出按钮边框；起止日历置于同一行，布局沿用个股详情。
- 周/月提示、三周期、日期校验、图表数据和任务历史契约不变。

## 根因

指数扩展只复用了`StockDailyKChart`，调用方仍把请求根数与数据长度直接拼装；
没有接收图表已有的实际可用/当前可见回调。终态effect仅执行查询失效，
没有复用数据总览的5秒任务跟踪清理。

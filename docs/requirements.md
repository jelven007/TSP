<a id="1-产品目标与范围"></a>
## 1. 产品目标与范围

<a id="11-产品定位"></a>
### 1.1 产品定位

TSP 是本地优先、可部署到服务端的 A 股行情分析与量化研究工作台。用户应能沿“取得可信数据 → 查看市场 → 配置指标与策略 → 检验历史表现 → 监控与模拟观察 → 保存并复测结论”完成闭环。

产品目标分为三层：

1. **盘中可用**：5,000 多只股票的行情持续更新，价格、指标与统计的时点清楚；采集、通知、历史写入和研究任务互不拖垮。
2. **研究可信**：历史范围、缺口、证券状态、输入版本和成交假设可追溯；数据不够时返回明确限制。
3. **规模可扩展**：支持面向十年历史的数据管理、快速筛选与批量回测，计算范围和成本可预估，原有小规模工作流保持可用。

<a id="21-盘中观察流程"></a>
### 2.1 盘中观察流程

数据源能力与交易日检查 → 获得当前市场快照 → 按需查看价格／指标／市场统计 → 定位标的 → 配置监控 → 查看触发证据与后续表现。

基础行情、复杂指标和通知各有状态。复杂指标预热不能阻止基础行情展示；数据缺口之后必须重新建立连续监控基线。显式历史视图不被最新行情自动改成当日。

<a id="22-历史研究流程"></a>
### 2.2 历史研究流程

选择历史范围与精度 → 查看覆盖及可信度 → 固定输入版本 → 预估读取与计算范围 → 运行筛选／回测 → 查看结果、失败及警告 → 保存候选／导出 → 用同一版本复测或显式创建新试验。

日线、分钟和秒级是不同输入契约。日／分钟初筛只在策略允许且不改变因果语义时减少候选；需要连续过程的策略保留完整预热与退出窗口。

## 3. 角色、对象与共享状态

<a id="31-权限模型"></a>
### 3.1 权限模型

角色名称用于产品分工，实际授权复用当前管理员／租户权限和 API scope，不另建平行权限系统。

当前系统角色为“管理员”和“租户”；下表“租户管理者”表示获授权的职责，不代表
已提供独立的成员邀请、协作审批或逐对象分享页面。已有私有业务按租户隔离，
助手历史进一步按账户隔离；独立模式多邮箱登录不构成完整租户隔离。
管理员默认具备租户业务能力；完整多租户启动时为缺少默认租户的有效管理员建立
个人空间，私有业务默认使用该空间。已选择的租户保留，切换后按目标租户隔离访问。

| 操作 | 获授权研究用户 | 租户管理者 | 平台管理者 | 外部 Token／AI |
| --- | --- | --- | --- | --- |
| 查询公共行情与质量 | 数据访问权限范围内 | 同左 | 按管理权限 | 对应读取 scope |
| 编辑策略／因子／监控 | 自有或被授权对象 | 租户内已授权对象 | 不自动获得私有研究读取权 | 仅已开放的动作与确认路径 |
| 提交／取消研究任务 | 自有或已授权任务 | 租户授权范围内 | 可管理容量，不篡改用户结果 | 对应执行 scope 与对象权限 |
| 发布公共数据版本 | 无默认权限 | 无默认权限 | 显式管理权限 | 不直接开放 |
| 删除／归档研究版本 | 自有结果且无活动引用；按确认规则 | 租户管理授权范围 | 公共保留政策及引用校验 | 不绕过管理确认 |
| 模拟账户操作 | 对该模拟账户有操作权 | 按租户授权 | 无默认越权 | 保留现有模拟交易 scope；MCP 不新增券商能力 |

“用户账户／租户”是身份范围；“模拟账户”是虚拟资金账本，二者不能混为一谈。

### 4.1 访问、账户与系统管理


面向：部署者、管理员、研究用户和外部调用者。起点：进入服务、切换身份、维护配置或接入外部工具。

**当前范围、权限与状态**

当前账户、角色和开放接口已实现；大规模发布治理和新的历史开放能力仍为目标。

管理员/租户与 API scope 分开校验；隐藏菜单不改变授权，管理员私有操作明确目标租户。

当前部署模式、菜单与会话边界以总纲第3章和实现索引为准。独立服务的多邮箱共享空间、Windows管理员个人空间、完整多租户必须分别验收。设置依次为账户、数据源、模型设置、实时监控、超时设置、菜单设置、扩展页面、开放接口、系统设置，普通租户仅账户设置。注册成功不等于公共行情已完整同步；配置输出预算不等于每日AI费用硬限额。

全新初始化预置 `admin/Admin123` 用于首次登录；邮件服务器和授权码由受控配置提供，
未配置时注册验证、找回和邮件通知不可用，不能从默认账号推断邮件已可发送。
已修改密码、已有身份及自定义 SMTP 保留。
完整多租户管理员缺少默认租户时自动建立个人空间；并发启动和中断重试复用同一
初始化记录，保留已选择租户、密码与私有数据，不启用已停用账户。
Windows 另行启用单机管理员模式；macOS/Linux 默认开启多租户与账户认证，
注册/找回在首次初始化自动开启，默认注册口令 `天王盖地虎`，自定义口令保留。
真实租户使用 SQL 隔离，需先准备双库及内部平台服务；旧独立模式可显式选择。
验收覆盖无 dotenv 的平台默认值、空模板、重启、密码修改、注册/找回和完整多租户运行角色初始化。

固定版本解决复测一致，不单独认证退市池、财务修订或历史真实度。数据发布与研究可信度分别判断。日/分钟初筛不得改变因果、预热、退出和共享资金语义；一分钟不同秒的最值不能拼成同时命中。过程型策略保留完整连续窗口。

结果至少保存输入版本、定义/代码/配置/环境、实际范围/精度、成本、成功/失败数量、交易/净值、未成交/未平仓、质量限制和可复测状态。无数据、不合格、无信号、执行失败分开。独立实验可并行，共享资金按时间推进；不能加总证券收益冒充账户净值。

### 4.7 监控、通知与模拟交易账务


面向：观察用户、模拟账户操作者与维护者。起点：启用规则、提交模拟订单、处理权益或复核异常。

保存规则/账户 → 等待有效输入 → 触发事实/生成订单 → 通知/撮合 → 核对账本/应收/净值。

**当前范围、权限与状态**

监控/模拟/公司行为事件已实现；策略组多租户接线、状态页面和完整交易日跟单仍待验收。

规则、渠道及模拟账户按租户与对象权限；Token保留现有paper:trade范围；MCP不提供下单。

触发、投递、订单、成交和结算是不同事实；通知失败不阻塞行情或重新生成信号。策略组共享当前只接入独立行情服务，配置/状态API、前端编组、多租户接线和交易日跟单未完成。通用规则逐快照，过程型规则不能用latest-only吞掉中间过程。

模拟交易保留T+1、费用、滑点、原价限价、待买资金与待卖可卖量占用、退出优先和最保守组合限额。公司行为独立于复权：登记/除权/到账/上市/缴款日期分别有证据；未知日期或修订冲突暂停相关账务/撮合与定版净值，不能从缺事件推断无权益。新事件账户与legacy模式不自动切换，含新账本回退匹配代码并保护新写。

### 4.8 AI 助手、会话与复盘报告


面向：使用AI的研究用户与管理员。起点：打开助手、申请受控动作或生成/读取复盘。

查询获授权上下文 → 生成或工具请求 → 确认动作 → 跟踪结果 → 完整报告/会话同步。

**当前范围、权限与状态**

协议、受控工具、会话同步和报告已实现；生成内容不能补齐数据事实或保证未来收益。

身份、租户及scope与普通操作一致；每次动作执行复查权限，生成历史不恢复未确认操作。

## 5. 跨模块数据与量化规则

以下定义供所有需求引用；实现技术可以调整，行为不得改变。

| 规则 | 统一定义 |
| --- | --- |
| 时间与交易日 | 使用实际交易日和北京时间；事件瞬间、观测时间、历史可得时间与当前导入时间分开；时间窗默认左闭右开并声明例外 |
| 精度与类型 | 日线、可信分钟、采样秒级、逐笔分别声明；快照不能恢复采样间高低点、逐笔顺序或队列位置 |
| 价格 | 技术特征的复权口径与绝对价／成交／涨跌停原始价分开；复权锚点和适用日可追溯 |
| 单位 | 比例小数／百分数、金额元、股数／手、累计／增量在边界明确；不根据值大小猜转换 |
| 历史可得性 | 财务、股本、状态、行业与数据修订只能在可得时间后用于决策；首次留档前未知不倒填 |
| 缺失与空值 | 未知、零成交、停牌、无能力和失败分开；严格窗口不补零／前填后声称完整 |
| 覆盖率 | 保留预期交易日／证券／时间范围和有效分母；退市池分母未知时不显示 0% 缺失 |
| 发布与修订 | 对目标大规模路径，固定快照指向不可变日段；修订生成新版本；现有 generation／原子发布继续有效 |
| 指标更新 | 日／分钟暂定值更新不构成一个新已完成周期；同一输入／参数共享计算，陈旧结果标记真实输入截止 |
| 筛选因果 | 候选裁剪不能改变策略语义；分钟最值不是分钟开始可得信息；所有联合条件在声明的同一时点判断 |
| 成交假设 | 信号时间、到达／可成交时间与成交时间分开；费用、滑点、数量、资金、T+1、价格规则与未平仓明确 |
| 复现与版本 | 数据、定义、参数、代码、依赖、日历及执行语义共同识别试验；固定输入解决一致性，不单独证明历史真实 |
| 信号偏移与周期 | 日线条件偏移按证券实际存在的行情记录计数，空字段记录仍占一根；收益标签按全市场交易日轴；分钟滚动不跨午休/跨日，两者不互换 |
| 研究统计 | 盈亏比为已平仓盈利/亏损单平均收益率之比；金额PF为净盈利金额总和/净亏损金额绝对值总和；净期望为全部已平仓扣费后收益率均值，包含零收益 |
| 未平仓与归因 | 未平仓损益影响账户估值但不计入已实现胜率/PF/净期望；因子归因使用入场信号日快照，仅解释当次胜/败组差异，不认证因果贡献 |
| 提醒与账务 | 持仓提醒成本/数量只供生成价格和到期监控，不占用现金、持仓或下单；模拟交易账户独立维护订单与事实成交 |
| 公司行为金额与成本 | 现金以每股税前元计，金额四舍五入到分；送转摊薄单位成本但不改总成本，配股增加实际缴款成本，现金红利单列并保留原持仓成本 |
| 权益与可用量 | 总资产=现金+持仓市值+应收资产；应收现金不能买入，应收股份计敞口但未上市不可卖；未认购配股权未估值，不能据放弃配股前后总额证明账务守恒 |
| 默认与历史兼容 | 缺省值只补缺失字段；有效已存路由/关闭状态、旧自然日窗口、旧因子账务继续读取，修改当前配置不追改历史记录 |

具体原有字段契约见[CONTRIBUTING.md](../CONTRIBUTING.md)。新增查询存储不能把当前 enriched 的换手率、分钟墙钟或盘口单位悄悄改成另一种口径。

## 2. 应用版本规则

主应用版本采用`a.b.cd`，末段不补零。本地迭代、提交、功能分支推送和本地合并不加号。
远程main每次集成push由CI自动递增一次；版本分配、质量门、发布及部署分别判断。
完整规则见[CONTRIBUTING 10.1](../CONTRIBUTING.md#101-主线版本规则)。

```bash
python3 scripts/check_version.py --current VERSION
```

不手改VERSION或锁文件来消除开发与运行环境差异。

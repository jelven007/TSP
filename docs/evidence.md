# 验证证据与历史报告

2026-11-16主线移除了 `reports/` 和 `screenshots/`。当前仓库不再要求这些目录，
也不恢复其中的报告或图片。已移除报告的引用仅保留历史说明，不作为当前版本验收证据。
用户本地报告、Excel、冻结研究输入和受控审计记录继续保留。

需求编号基线移至 [requirement-ids.json](requirement-ids.json)，内容保持原冻结集合。
[需求手册](requirements.md)仍是唯一功能定义；检查继续拒绝缺失编号、重复定义、
无效模块、状态和本地链接。目录移除不关闭文档或需求门禁。

当前发布过程见[发布流水线](release-pipeline.md)，各轮范围见
[升级记录](upgrade-20261117.md)。本轮候选测试和实际部署分别签收，
最终脱敏回执归 `deliverables/operations/`；正式身份以通过质量门的不可变版本为准。

## 发布、运营与回滚

进入 PR 前完成整合态回归、前端 test/lint/build、版本一致性、差异与文档检查；
PR 经复核且质量门通过后合并。CI 自动改号并在源码质量门成功后创建标签。
运营说明必须分别列出源码新增能力、生产已部署修复和未解决故障；
不承诺 Win10 真机全功能、全交易日稳定性或更高等级并发容量。

支持集合为最新成功源码版本及最近两个历史版本。更早 Git 标签若受不可删除
规则保护，保留为审计点并报告限制；不改写提交历史或取消保护。
删除归并分支前检查工作区和未推送内容，未提交现场不能随分支清理。
生产回滚仍要求先停写、恢复对应数据库与目录路由，再启用目标版本；
不得因仓库合并自动切流或删除用于诊断、研究和恢复的数据。

# 2026-11-17统一升级候选

本轮从远程 `0.4.64` 建立隔离候选，整合两端 `0.4.61` 已部署修复。
版本由合并后的 main CI 分配；本文是候选说明，尚不认证正式发布或双端升级。
不新增收益回测，不改写历史任务、策略保存值、账户费用或交易账本。

## 变化与兼容

- 参数已移出的自定义S01通过通用回测表单设置资金、权重、持仓数、最大总仓位、
  佣金、印花税、滑点、最低佣金和额外过户费。S01建仓仍使用已支持的五分钟容量窗口；
  通用清仓选项按实际信号日与成交时点执行。显式旧冻结执行参数保留原优先级。
- 共享低振幅成交额评分接通日线、矩阵和分钟因果前缀。证券资格与评分完整性分别判断，
  不以评分缺失改写完整股票池。S02原源码评分和已保存参数不被通用设置覆盖。
- 扩展表仅加载本次引用的列与信号依赖，历史回放继续拒绝快照未来值。
  Broker在移除退出容器前读取真实 `OOMKilled`，区分已确认内存不足和其他退出原因，
  保留退出码并释放任务容器、租户和计算槽。
- 1分钟采集在取数前分配持久序号，随Parquet元数据原子提交；迟到旧响应和同序号冲突
  不能覆盖较新记录。公共版本保持实时截止，拒绝的API补拉行改读已提交分钟。
- 主线已删除报告和截图目录；需求编号基线移到 `docs/requirement-ids.json`，
  旧报告引用改成历史说明，当前导航使用[证据入口](evidence.md)。文档门禁继续严格校验。

股票池继续按 `scope_only_v3`；S02及尾盘建仓实时新入场截止仍为14:55:00，
尾盘启动与30秒确认按当前保存值执行。S01选股、入场和出场信号来自各端当前保存定义，
本轮不批量迁移或用研究快照替代它们。SQL迁移校验和与原生组件版本保持。

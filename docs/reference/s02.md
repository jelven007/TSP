## 参数与执行

参数编辑顺序参考自定义S02的阅读路径，但保留内置策略自身规则：

| 原分组 | 调整后分组 | 参数 |
| --- | --- | --- |
| 选股与退出 | 尾盘选股 | 前日涨幅、14:30涨幅、流通市值、20日均额、上涨比例 |
| 分钟成交与资金 | 买入与仓位 | 初始现金、单票净值比例、额外单票上限、持仓上限 |
| 选股与退出＋完整早盘卖出 | 次日卖出 | 净止损、毛止盈、兜底时间、卖出截止 |
| 分钟成交与资金 | 费用与容量 | 分钟参与率、滑点、佣金、最低佣金、过户费、印花税 |

该调整仅在前端生成展示副本，设置页、回测参数页及参数扫描页一致；
后端参数定义、默认值、选股买卖逻辑、策略逻辑版本和历史结果身份均不改变。

指定3052成员研究池，按上市日期限制可用成员。14:30前日涨幅0.5%～6%、

市值范围内股票上涨比例至少60%。1分钟MA5连续6次上升、5分钟MA5连续3次上升。
历史股本优先用已公告记录，缺少历史记录时保留当前股本降级，不声称严格PIT。

“选”保留全部达标股票并显示买入优先级；达标数量超过当时配置的持仓上限
时按14:30涨幅降序，否则按前20日均额降序，同值按代码升序。默认上限为5；
历史页面按保存时参数排序。“买”最多5候选、5持仓，单票含费预算为净值20%及可用现金。
14:32按分钟最高价成交、100股整手，最多参与该分钟成交量50%。

次交易日卖出遵守T+1，扣费净止损先于毛止盈。同分钟双触发按止损处理。

## 查询入口

单策略运行省略周期时采用策略声明的`1m`。显式`timeframe=1d`仍不支持；
日线只是选股辅助窗口，执行与结果属于分钟周期。

“开启策略监控”保存校验也采用声明的`1m`；新建、编辑、停用及重新启用
均支持。2026-11-01本地修复及验证见[监控周期验收](../../reports/s02-monitor-timeframe-20261101.md)。

策略页“策略池”加入s02，点击卡片查看所选交易日的“卖／选／买”。
股票代码和名称可打开个股详情并在当前Tab内切股；加载失败时提供刷新重试。
“历史结果”支持日期、周期、历史名称或版本筛选，每交易日只有一份记录；
重跑更新同一条，缺前日完整组合状态时明确提示。

回测页“任务历史”可按s02筛选，查看或导出已持久化任务。
原15组五资金与滑点压力历史任务、92份每日记录均在租户SQL中保留。
历史身份改名时重建结果键，保留计算时间、成交、费用、收益、净值及原执行来源。

### 连续回测的日线依赖

S02沿`StrategyBacktestService`进入专用分钟执行器，日线预热窗口为25交易日。
加载计划保留原始高低收盘价、成交额、换手率及证券股本元数据；
涨停、跌停和炸板三列日线信号既不请求计算，也不列为必需基础列。
共享加载器仍检查必需字段，实际缺分钟、缺交易日日线或截止容量不足时明确失败，
不跳过交易日或虚构清仓。通用分钟及S01加载计划仍计算各自要求的日线信号。

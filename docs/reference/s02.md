## 股票范围、选股与信号

完整池是策略自身范围列表：板块与分组取并集，保留该区域ST／停牌选择。
当前要求及本地运行口径为`strategy_scope_v4`；行情缺失、数值过滤、命中、评分及展示不缩小池。
当前S02参考覆盖为沪深主板、排除ST及停牌，`overlay_filter=[]`。

| 环节 | 规则 |
| --- | --- |
| 预选 | 精确前交易日价格4～150元、换手1%～11%、涨幅0.5%～6%、流通市值50～500亿元；按当前保存覆盖执行 |
| 名单 | 目标交易日完整冻结预选；买入仅在该名单内触发，返回全部合格命中 |
| 入场 | 保存信号14:30启动、30秒确认，使用14:30启动分钟的已完成数据 |
| 广度 | 有效完整池上涨占比至少60%；缺有效指定分钟价格或精确昨收的成员剔除，全无有效成员为数据不足 |
| 个股 | 涨幅0.8%～4%，7个1分MA5及4个5分MA5严格递增；缺MA窗口只跳过该股 |
| 排序 | 冻结ATR14÷昨收降序；同值按触发涨幅降序、代码升序；ATR未知保留信号并排末尾 |
| 截止 | 策略交易日14:55:00整允许，超过拒绝实时新入场；卖出及明确历史重算独立 |
| 出场 | 次交易日早盘相对精确未复权昨收涨／跌6%；检查、止损和兜底时钟读取实际保存信号 |

早盘清仓模板支持全天时钟；兜底为立即停止所有股票卖出的截止，
不再对余股产生新卖出窗口。尾盘走强的结束时间同时限制买入信号后的最长买入时段，
超过停止买入。新分钟回测建仓从实际确认后的可成交分钟到结束时间（含），
清仓从实际触发后的可成交分钟到兜底前（不含）；保留午休、T+1及真实容量。
本项源码修改不自动改变保存时钟、旧冻结回测或正式环境。

账户资金、仓位、自动跟单、费用及成交限制分别属于各自配置，不作为策略选股条件。
监控启停与策略池选择、结果查询独立。每日卖／选／买任务按冻结的信号时段调度，
成功、拒绝、失败及重试期限分别保存；当前内部编排见
[strategy_monitor_tasks.py](../../backend/app/services/strategy_monitor_tasks.py)。

新监控契约下，S02恢复普通策略启停，不再保有系统关键任务：
选择策略默认不开启，显式开启后每个交易日分别生成卖／选／买三个任务，取消同时撤销后续执行。
选在20:00～22:00只按股票范围＋数值过滤执行，评分降序保存下一交易日资格。
该窗口内启动或开启监控即时检查所有已开启的自定义／AI策略；
正常按日归档（含空名单）算完成，缺失或失败在窗口内修复重试，保存详细监控回执。
买在14:30:15开始广度计算，失败修复重试严格截止14:30:30之前；
广度正常未通过时当日该信号结束。14:30:30计算其他个股条件，
成交额、换手、振幅、涨幅及量比固定使用14:30启动数据，双MA5复用共享内核；
失败修复重试至14:55，成功名单同步下一交易日卖。
当前保存出场窗口09:30～11:30，止损检查10:50；每股首次触发保存并提示。
正常通过、不通过与失败均在监控中心保留详细回执，完成结果不被后续分钟重算。

## ATR与单股异常

连续15个已完成交易日的一致复权日K构造14个
`TR=max(high-low, abs(high-previous_close), abs(low-previous_close))`，
取简单均值并除以精确前交易日复权收盘价，不使用Wilder平滑。
预选保存ATR、比率及参考日，买入复用该快照；缺窗口保留资格、指标未知。
预选排名分数为`100×(N-r)/(N-1)`，N为可计算成员数，单只50分。
通用评分覆盖不能替换源码拥有的排名。

盘后预选按股票隔离收盘价、分钟缺失、重复日线和定版时钟异常，
保存异常代码、原因及覆盖计数，其余有效股票继续，完整池保留。
无法定位单股的整份证据错误明确失败；全无有效成员不能冒充成功零命中。

## 卖／选／买查询

选读取目标日已保存资格，买读取目标日实际入场信号，
卖读取同策略精确前交易日成功买入信号派生的关注名单。三页名单均不证明实际成交。
持久归档、日期指针和正文在同一事务发布，历史GET只读已保存结果，
不加载当前行情、因子或Compute。完整数组通过虚拟渲染显示，不裁剪成员。

缺投影、缺前日归档、未确认、生成失败及超时分别显示。
成功确认的零买入保留完成状态，后续截止不能改为未确认。
缺明细时，只有同策略、同日、同定义、确认至截止内成功的零买入回执可确认次日卖为空；
失败、非零、其他日期或定义都不能补造名单。

日期切换、重复选择当前日期及读取次日缓存不触发策略计算。
页面验证须实际选择S02，并覆盖无摘要、缺归档、历史日期及卖／选／买切换。
历史信号重建、收益回测和部署分别判断；本次文档清理未生成新名单或运行回测。

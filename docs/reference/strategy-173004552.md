# 173004552 三分支策略

本页保留参考范例的身份及原始研究口径。当前 S05 采用
[独立四维评分实现](s05.md)，盘后“选”与新分钟回放不再调用本参考评分器。
当前保存的信号参数、调度和市场路由以S05正文及实际保存定义为准；
下述示例不替换用户保存值，既有冻结结果保留。

独立 ID 为 `custom_mvxxcs05`。保存[策略源码](../../examples/strategies/s02_173004552/strategy.py)、
[六个触发器](../../examples/strategies/s02_173004552/signals.json)及
[触发器选择](../../examples/strategies/s02_173004552/trigger-overrides.json)。
S01、S02、S03沿用各自保存定义、归档和既有权威输入通道。S03的预选来源仍为原S02。

沪深主板，排除ST、停牌和参考日除权股票。示例源码含日线数值条件，实际选股以已保存覆盖为准。
盘后按技术40%、资金30%、情绪25%、基本面5%计分，
同分按代码升序。缺失评分子项按中性50，异常个股的定版日线隔离。前50名参与入场，
完整池和预选名单分别归档。近14个自然日有已观察且发行人匹配的分红实施公告的股票跳过入场。

冻结精确的T-21至T-1沪深主板市场广度。最近五日平均上涨占比≥55%，或T-1比T-6
下降至少35个百分点时走尾段；否则T-1比T-21变化≥-32个百分点且最近两日平均
上涨占比≥50%时走低缺口；其他情况走板块。缺精确归档时等待，不从目标日行情重建。
三个入场点可以同时选中；实际每天只计算盘后指定的一个分支，启动后30秒确认。

| 分支 | 启动与入场 | T+1观察／止盈／止损／兜底 |
| --- | --- | --- |
| 尾段加速 | 14:05；5分钟涨幅≥0%，15分钟≥0.10%，相对昨收0～7%；按5分钟涨幅排序 | 09:49／1%／1.5%／09:59 |
| 低缺口资金趋势 | 14:14；开盘缺口≤1%，相对昨收-1～6%，日内位置≥65%，15分钟涨幅≥-0.15%；按资金70%＋技术30%排序；第一名相对昨收涨幅达到2.50%时全支跳过 | 09:43／2.5%／3%／13:25 |
| 板块强势综合 | 14:40；T-1上涨占比≥48%且站上MA20比例≥45%，相对昨收涨幅≤7%；按四维综合分排序 | 10:13／4%／3%／10:53 |

各分支同优先级以四维名次、代码定序，只取第一名。信号后第2～11分钟可买；
次日按买入分支判断出场。卖窗从触发后的首个可交易分钟起至多30个自然分钟，
午休不延长，最晚含14:00。分钟撮合基准按高价买、低价卖，成交参与率10%；
逾窗余量保留实际状态，不重新开委托。实仓、费用和自动跟单须另行配置。

# S03 当前实现

策略名称 **s03**，稳定ID **`custom_mvxxcs03`**，界面说明“s02升级版”。
本页唯一维护当前规则、参数、计算与异常契约、源码及测试入口；
需求、开发、测试和运维手册引用本页。参数依据2026-11-25读取的本地、线上
已保存源码、有效覆盖及关联信号，两端一致；后续用户保存值优先。
本页不保存恢复过程、补丁流水或收益结果。工作区源码整理、运行安装和页面验收
分别记录在当次回执，修改文档或安装源不代表运行定义已经更新。

## 1. 定义与完整股票池

自定义股票分钟策略，结果分卖／选／买；唯一当前安装源为
[s03.py](../../examples/strategies/s03.py)。运行定义须通过现有源码保存接口
更新各租户`strategy_sources`，修改示例本身不代表运行生效。
唯一入场项`csgi_late_session_strength_s03`、出场项`csgi_morning_liquidation_s03`，
均启用；没有启用均线金叉或长均线上升入场项。

S03自己的范围为沪主板、深主板，排除ST及已确认停牌。
完整当日池使用`strategy_scope_v4`，板块及所选分组取并集。
当前价格、流通市值、涨幅、量额、换手数值条件及附加过滤均为空。
S02候选、五维前30、缺行情、最终命中和展示上限均不缩小完整池。
S02只提供冻结评分候选，其当前规则见[S02](s02.md)。

## 2. 盘后预选

### 2.1 依赖、时钟与保存

T日北京时间 **22:00:00～23:00:00** 运行，结果归属精确下一交易日D。
只消费同一用户S02（`custom_mvxxcp88`）在T日 **21:00:00～22:00:00**
成功完成的预选归档，校验目标日D、源日T、成功状态、身份、21点计划及生成时刻。
冻结整个依赖和SHA-256，重试／重启复用，不重新执行S02，不用22点后补造名单。
两个窗口结束整秒包含在内，超过即拒绝实时提交。

当前完成证据须为`s03_five_dimensions_v1`、日期匹配、无整体错误且不超过30只，
正常空名单有效。`DailySelections.selection_record`优先读五维口径槽，
原槽已有兼容归档则复用；旧口径不使新任务跳过评分。
启用A/B但缺兼容归档时，买任务明确等待，按交易日历和23点截止提示最早完整周期日。
页面只读不补算；独立卖任务仍按已确认名单执行。历史不可变记录保留原ID和内容。

### 2.2 输入与五维评分

按股票读取截至T日最近65条实际已保存完成日线，至少60条，末条必须属于T日；
跨停牌补读实际记录，不补造缺日线，不借D日行情。
各维度0～100分，令`L(x,a,b)=clip(100×(x-a)/(b-a),0,100)`：

| 维度 | 综合权重 | 原始指标、内部权重及映射 |
| --- | --- | --- |
| 技术 | 40% | 收盘>MA5>MA10>MA20>MA60的4项相邻比较，每项25分，层级占30%；MA20五日变化20%（−1%～3%）；20日动量20%（−5%～20%）；`(DIF-DEA)/收盘`15%（−0.3%～0.6%）；MA20绝对乖离15%，取`100-L(绝对乖离,4%,18%)` |
| 资金 | 20% | 超大单＋大单净流入÷同日成交额：当日35%（−10%～15%）、近5日均值30%（−5%～10%）、近20日均值20%（−3%～6%）、近5日正流入比例15%（20%～80%） |
| 情绪 | 20% | T日涨幅25%（0%～6%）、收盘在当日高低区间位置30%（比例×100）、成交额÷20日均额25%（0.7～2）、本次上下文有效T日线上涨广度20%（比例×100） |
| 基本面 | 10% | 净利润增长30%（−20～40百分点）、ROE25%（0～15百分点）、经营现金流÷净利润25%（0～1.5）、负债率10%（`100-L(x,30,85)`）、原始收盘÷年化估算EPS对应PE10%（`100-L(x,15,60)`） |
| 消息 | 10% | 基础50；正事件每项＋10、最多2项，负事件每项−25、最多2项，再截断 |

综合分=技术×0.4＋资金×0.2＋情绪×0.2＋基本面×0.1＋消息×0.1。
综合分降序、同分代码升序取最多前30；保存排名、分项、原始输入、覆盖、异常、
观察证据及继承的S02参考字段。MACD用首条实际读取收盘初始化EMA12/26，
DEA从0递推；高低相等且收盘一致时收盘位置取0.5。

资金及成交额均为元，逐条匹配该股最近20条日线日期。
财务公告日早于T、报告期不晚于T，指标／利润／现金流三表报告期一致；
EPS按报告期月份×`12/月数`年化。已知非正利润的现金流项、非正EPS的PE项计0，
真实缺字段不补中性分。

公告使用T日前10个自然日，T日公告不参与；冒号前发行人名匹配证券简称，
统一全半角、空格、ST前缀，同公告去重。
正词：中标、签订合同、业绩预增、扭亏、回购进展／股份实施、增持完成。
负词：立案、退市、风险警示、减持、亏损、下修、处罚、违约、无法偿还、诉讼、仲裁。

只消费标准化时序扩展和已保留财务观察修订。资金默认`ext_sina_money_flow`，
公告默认`ext_announcements`；`META.selection_data_sources`可用`funds/news`
指定同字段契约的唯一数据源。观察时点不晚于本次计算，分区读取前后身份稳定；
不直接调用供应商SDK，不逐股混搭资金口径。

### 2.3 自选同步

新五维归档成功后，在同一 **22:00～23:00** 任务替换固定自选组`s03`：
移除旧关系，按冻结选名单顺序写新名单。只属于本组的旧股票及策略标签删除；
共享股票其他组、备注及策略标签保留，组ID、名称、颜色保留。
成功空名单清组，失败不清组；同摘要幂等，较老归档不能覆盖较新名单。
Full与归档共用租户事务，失败整体回滚；文件模式保留成功评分，
组写入失败恢复原文件，窗口内只重试同步。
缺组、未保存、重复／过多、日期不符、窗口外不清组。
提交后业务事件刷新自选及分组，不受实时行情刷新开关影响。

## 3. A/B入场筛选

### 3.1 固定评估与时间边界

信号 **s03_早盘建仓 / `late_session_strength_s03`**，
模板ID仍为`late_session_strength`，名称不决定时钟。
当前 **10:00启动、延迟30秒、10:00:30确认、10:30截止**，
读取10:00启动分钟及之前已完成数据。当前未声明独立阶段或额外广度观测，
共用池广度下限为空，调度直接在确认时刻派发个股计算，不运行10:00:15广度阶段。
B组广度条件读取前日五维归档中的市场广度，与当日完整池广度不同。

**10:00～10:30不是持续逐分钟重新筛选区间。**
10:30是同份启动输入补数、重试及新买提交截止。
合法零命中为终态，不因10:01以后行情重选；未到确认等待，
异常在有效窗口修复并重试固定输入，超时／取消／配置或租约变化拒绝迟到提交。
S03的10:30早于全局14:55实时新入场上限，以较早边界为准。

### 3.2 当前已保存条件

共用涨幅、振幅、金额、换手、量比、1分／5分MA5计数及池上涨比例条件均为空。
共用有效条件先AND，再要求A组全部条件或B组全部条件；双命中归A。
组可停用，单条件null不参与；启用组至少一项条件、至少一组启用。

| 条件 | A组 | B组 |
| --- | --- | --- |
| 综合分≥ | 55 | 70 |
| 技术分≥ | 75 | 65 |
| 资金分≥ | 70 | 40 |
| 20日动量 | 18%～40% | 5%～50% |
| MA20乖离≤ | 100% | 25% |
| MA20五日变化≥ | 1% | 0% |
| 五维排名 | 2～20 | 6～25 |
| 前日上涨广度≥ | 未启用 | 25% |
| 今日开盘缺口 | −1%～10% | −5%～1% |
| 相对开盘涨幅≥ | 0.8% | 未启用 |
| 日内价格位置≥ | 90% | 未启用 |

分数、动量、乖离、均线变化、广度只取精确前交易日五维归档。
开盘取09:31分钟open；缺口=开盘÷原始昨收−1，相对开盘涨幅=10:00现价÷开盘−1；
位置=`(现价-截至启动分钟最低)/(截至启动分钟最高-最低)`。
百分比配置存百分点、归档比例读取×100，边界含等号；
入场乖离用有符号`bias20`，不是评分中的绝对乖离。
高低相等时位置未定义，启用组缺值不能通过，另一组仍独立判断。

### 3.3 排序与结果

逐股完成A/B判断后，A组优先；A组按前日五维排名升序，
B组按资金分降序、五维排名升序、代码升序。双命中归A。
输出`entry_group/entry_priority/selection_rank/selection_score/entry_fund_score/entry_emotion_score`。
前日五维分和原排名继续用于已启用的A/B筛选条件；
资金分是B组排序的必要值；情绪分不参与当前B组排序。
引擎在展示截断前按该顺序映射`score`到0～100，单只50；
`selection_score`保存前日五维分，`strategy_score`保存源码投影原分，
不作为额外筛选条件；整理后的安装源直接投影冻结五维分。
“选”页面按五维排名升序，“买”按实际保存的`entry_priority`展示。
当前选名单仅投影S03使用的结果字段，S02的冻结依赖原样保存。
每股保留真实首次命中分钟，不能借最新分钟恢复触发；
参数、归档或排序声明身份变化使状态失效。声明只应用于当前源的私有执行快照，
不改写输入归档；历史冻结源码分别保留自身排序契约。
已完成的历史归档保留原顺序；买及下一交易日卖名单由权威事务发布，
通知去重且沿用顺序。展示上限100不参与完整池或前30定义。

### 3.4 每次个股计算与异常分支

实际顺序是输入校验→固定分钟去重→有效价格→共用条件→1分MA→5分MA→A/B→
首次命中投影→最终排序→任务回执。共用条件与两项MA当前为空，回执标记`skipped`。

| 子过程 | 当前输入与处理 | 异常、空结果及重试 |
| --- | --- | --- |
| 调度与加载 | 已保存信号确定窗口；10:00:30派发`stocks`，使用冻结选名单与完整池的交集 | 未到时刻等待；上下文输入错误记失败，窗口内重试，正常终态不重开 |
| 预选校验 | 归档必须属于D、源日为精确T、五维口径，成员格式有效 | 缺归档在执行入口等待；日期、口径或结构错误整份失败；真实空归档与缺归档分开 |
| 分钟预处理 | 当日交易时段、完成态上界、再截到10:00；同股同分钟取最后一条 | 不填缺口、不消费10:01以后行情；无池或缺基础列失败 |
| 有效价格 | 精确10:00分钟收盘为有限正值；未收到或无效的股票留缺失名单 | 全无有效价格失败；部分缺行/坏价隔离，有效股票继续。当前普通S03路径不要求所有候选启动行到齐后才冻结 |
| 共用数值条件 | 当前为空；共享实现按启用条件声明最少字段，累计量额仅到启动分钟 | 非空时单股缺必要值隔离，全体数值候选缺依赖失败；真实阈值未过为正常淘汰 |
| 1分／5分MA | 当前跳过；启用时顺序取交集，5分先验证完整1分窗口再聚合 | 部分缺窗隔离；所有候选缺窗失败；完整窗口但不递增为正常淘汰 |
| A/B | 按前日分数/比例与09:31、10:00原价判断；A先算，双命中只保留A | 单组缺值记录原因，另一组继续；重复成员或无效排名隔离；有候选但全无可算组失败；可算但全未通过为合法零 |
| 投影与排序 | 每股取真实首次触发分钟及冻结五维分；A排名、B资金分决定优先序 | 投影或帧计算异常由外层转失败；不改写选股归档 |
| 冻结与提交 | 成功和合法零立即固定；输入异常按计划3秒后再试同份启动输入 | 3秒为下次计划间隔，不是执行耗时承诺；10:30整仍允许，超过或身份/世代/租约变化拒绝提交 |

部分缺启动行后形成的正常结果不会因后续行情到达自动补回；
明确历史修正与自然盘中运行分别记录，不能把后补结果称为原盘中已经完成。

## 4. 出场信号

信号 **s03_早盘清仓 / `morning_liquidation_s03`**：
**09:54开始、成本止盈3%、成本止损6%、14:30时钟清仓、14:58停止卖出**。
昨收涨跌幅、三分钟下跌及量比条件为空；策略级固定／移动风控、
最大持有及附加风险当前未设置。

信号名单来自前日确认买名单，与实际持仓分别处理。
实仓成本为剩余FIFO买入成交批次加权均价，不含费用；
只信号名单用冻结买入原始参考价并标记`buy_signal_reference`。
缺成本保存诊断，不以昨收代替，时钟清仓仍可生效。
逐股校验买入日期和交易日历，实仓再核对数量及可卖数量。
先查已完成分钟首次价格触发，再查同日新鲜报价（15秒，容忍2秒未来偏差），
最后在未提前触发时使用14:30时钟。
14:58整起禁止重开窗口；截止后保留早先触发只作诊断。
确认停牌持有等待，确认复牌按证据直接出场；
缺分钟不补造提前触发，时钟不因此关闭。
独立卖任务不依赖今日买／选成功，首次卖出不被后续空结果覆盖。
账户资金、仓位、跟单、费用、容量及T+1属于交易模块配置，信号命中不等于成交。

卖任务每轮仅处理尚未保存首次卖信号的成员，正常观察下一次计划间隔30秒，
失败下一次计划间隔3秒。单股日期错误直接跳过；成本缺失记诊断，
该股仍可在14:30产生时钟信号。分钟读取、日线读取或停牌证据读取异常各自保存；
已有卖信号仍累积，错误使本轮回执失败，未处理成员继续重试。
前日买归档明确为空时，卖任务正常零终态；缺前日买归档保持等待。
全部关注成员已触发才正常结束观察；未完成成员到14:58过期，已保存首次触发保留。
复牌证据直接出场由独立证据分支处理，实际任务派发仍受卖窗口限制。

## 5. 异常、修复与持久化

| 场景 | 处理及可见结果 |
| --- | --- |
| S02缺依赖／未完成 | 窗口内等待重试，不重跑造依赖，窗口后记录未完成 |
| 依赖日期、时钟、身份、摘要错误 | 整份证据失败，不借别日或晚补名单 |
| S02成功空候选 | S03成功空归档，无需评分数据，按事务清组 |
| 日线不足／重复／非正价格量额，资金缺值／重复，财务期不一致 | 逐股隔离，保存代码、原因、覆盖，有效成员继续，完整池保留 |
| 扩展源缺失／不唯一、缺观察时点、读取时分区变化 | 整份输入失败，不用单股兜底掩盖 |
| 有候选但全无可评分成员 | 明确失败，不能冒充成功零命中 |
| A/B归档缺失、日期／口径错误 | 等待兼容归档或报输入错误，不借当日收盘或别日 |
| 成员重复、排名错误、开盘／启动分钟或组必要值缺失 | 逐股隔离，另一可算组独立判断；全不可算失败 |
| 输入完整而条件不通过 | 合法零／正常拒绝终态，固定启动输入，不滚动重选 |
| 数据修复 | 原平台Provider→落盘→加工→发布，保存请求、版本、截止，租户不直接取上游 |
| 取消、配置、世代／租约变化或截止后返回 | 提交前重验，拒绝迟到结果，不发迟到买通知 |
| 归档／自选写失败 | Full整体回滚；文件恢复组且只重试同步 |
| 卖日期、成本、行情异常 | 单股原因保留；日期无效不卖，成本缺值不确认成本条件，独立时钟仍有效 |
| 今日窗口未开始 | waiting，前日失败不能把凌晨未开始任务改成failed |

回执保存阶段状态、原因、尝试、覆盖、修复截止及输入身份。
保留首次错误、首次回执及最近32次尝试。`failed`可在窗口内重试，
`success/rejected/expired/cancelled`为终态；正常零和失败零不可混同。
S03当前买任务为普通个股阶段，不将其他策略的独立广度汇合机制写成S03必需步骤。
Full由Worker持有租户事务、监控世代和计算租约，Compute只消费冻结上下文，
提交前重新核对；文件模式通过既有锁和原子写保存。事务未提交的结果不进入热缓存。
按日视图读取持久化卖／选／买归档和有界缓存，历史GET不读行情、因子或Compute；
查询键含策略与日期，业务事件失效相关页面缓存。
页面区分等待、失败、合法零、部分有效、原盘中未完成；
盘后补算不认证原盘中成功。卖／选／买及重载持久化逐项核验。

## 6. 回测与历史边界

启用A/B的分钟回测按冻结定义逐日重建S02候选，复用五维、
固定启动分钟A/B及早盘清仓账本，加载S02引用字段和至少65条完成日线。
普通研究消费冻结公共行情／研究快照，记录`retained_research_snapshot`、
依赖摘要、逐股覆盖及观察时点；后来采集／修订不证明当时可见。
严格研究只用T日21点前已观察证据，缺证据失败，并遵守其它研究治理门。
研究不写实盘归档／自选，不伪造S02历史调度成功。
旧冻结未启用A/B的信号保留自己的回放契约；
Date/Datetime按ISO编码参与身份，等价持久字符串不改变身份，未知对象拒绝。
通用账本保留最早完成分钟风控／清仓、T+1、容量、汇总费用、停复牌及截止余股失败；
冻结日线入场风险及混合其它出场触发器仍不支持。
新回测按[研究要求](research.md)用100万元和页面冻结费用；
源码与文档整理本身不发起回测、历史重算或部署。

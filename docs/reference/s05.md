# S05 · 四维前50：独立四维评分实现

当前本地策略为 `s05 / custom_mvxxcs05`。买入日为 T，精确前一交易日为 D。
D 日21:00～22:00，先完成 S02（`custom_mvxxcp88`）基础预选。
S05 在 D 日22:00～23:00冻结 `as_of=T / source_date=D` 的完整来源归档，
计算综合分前50只；22:00开始，23:00整仍可提交，超过23:00不再计算或提交。
缺来源时独立等待重试，不重跑 S02，不借用其它日期或 S03 的前30名单。

S05 自行实现技术、资金、情绪和基本面四维评分，权重分别为40%、30%、25%、5%。
盘后选股与新分钟回放调用 S05 自有 `services/s05_scoring.py`，
不再委托 `s02_173004552_selection.py`。综合分降序，同分代码升序。
少于50只保留实际数量；异常股票单独隔离，原候选非空但全不可评分明确失败。
缺失评分子项按参考公式给中性50，并记录缺失说明。

预选归档使用 `s05_four_dimensions_40_30_25_5_v1` 口径标识。
保存来源身份和 SHA-256、观察时点、四项得分、综合分、名次及覆盖计数。
当前三个入场信号复用通用分钟模板；盘后“选”同次计算并冻结下一交易日整数分支参数。
通用分钟执行与每日分支调度分开，不以旧专用入场执行器的META标记启用调度。
新归档使用 `s05_four_dimensions_40_30_25_5_v1_common_branch_v1` 槽，
记录 `entry_execution=common_template_v1` 和 `branch_code`；
同日读取优先该槽，原无分支通用槽、整数分支槽及历史归档不改写。
新评分来源记录 `scoring_implementation=s05_independent_four_dimensions_v1`。
原 `s02_*_score / s02_score / s02_rank / s02_entry_exclusion` 是既有归档与
买入消费者的兼容字段名，不表示调用旧评分器。已有归档及冻结回放不改写。

## 独立四维评分

各子项线性映射到0～100并截断边界，缺失子项取中性50。下列比例输入均为小数；
财务同比、ROE和资产负债率为财务标准字段的百分数数值。

| 维度 | 子项、映射区间与维度内权重 |
| --- | --- |
| 技术40% | 收盘→MA5→MA10→MA20→MA60四段向上排列，每段25分，缺值段12.5分，合计占30%；MA20五日斜率−1%～3%占20%；20日动量−5%～20%占20%；MACD柱/收盘−0.3%～0.6%占15%；收盘偏离MA20绝对值4%～18%反向占15% |
| 资金30% | 超大单与大单净流入合计/当日成交额：当日−10%～15%占35%，完整近5日均值−5%～10%占30%，完整近20日均值−3%～6%占20%，完整近5日正流入比例20%～80%占15% |
| 情绪25% | 当日涨幅0%～6%占25%；收盘在日内高低价区间的位置0～1占30%，高低相同取0.5；成交额/20日成交额均值0.7～2占25%；源日全市场上涨比例0～1占20% |
| 基本面5% | 净利润同比−20～40占30%；ROE 0～15占25%；同报表期经营净现金流/正净利润0～1.5占25%；资产负债率30～85反向占10%；原始收盘价/按报告月份年化基本EPS的PE 15～60反向占10% |

只消费精确源日D及之前已完成的日线，技术预热从2025-10-01开始。
财务公告日及报表期严格早于D；扩展资金、公告及财务修订按真实观察时点读取，
记录来源与缺项。冻结昨收与日线原始收盘必须一致，重复日线、异常价格及
源日高低价异常按股票隔离。近14个自然日发行人匹配的已观察分红实施公告
只标记禁止入场，不删除已排入前50的股票。

## 买入信号和排序

当前本地自定义信号标识为 `csgi_tail_entry_s05` / `csgi_tail_exit_s05`、
`csgi_low_gap_entry_s05` / `csgi_low_gap_exit_s05`、
`csgi_board_entry_s05` / `csgi_board_exit_s05`。
保存的条件、参数、时点和监控开关以当前配置为准。

三个入场信号均使用“尾盘走强 · 分钟入场”16项通用参数。
当前保存时点和已迁入的通用门槛如下；其它通用数值为空，不启用对应条件。

| 信号ID | 启动／确认／结束 | 已启用的新通用条件 |
| --- | --- | --- |
| `tail_entry_s05` | 14:05／14:06／14:16 | 最近5分钟涨幅≥0%，最近15分钟涨幅≥0.1% |
| `low_gap_entry_s05` | 14:14／14:15／14:25 | 最近15分钟涨幅≥−0.15%，日内位置≥65%，开盘缺口≤1% |
| `board_entry_s05` | 14:40／14:41／14:51 | 无 |

每日分支参数1为尾段加速、2为低缺口资金趋势、3为板块强势综合、4为均不满足。
盘后沿既有市场广度判断顺序冻结首个满足的分支：尾段为近5日平均上涨占比≥55%
或源日上涨占比相对5个交易日前下降至少35个百分点；低缺口为相对20个交易日前
变化≥−32个百分点且近2日平均上涨占比≥50%；板块为源日上涨占比≥48%且
站上MA20占比≥45%。使用精确T-21至T-1的21交易日证据；
现有专用字段仍存在时冻结其保存市场阈值，当前通用信号不新增这些字段或专用个股条件。

监控开启后，T 日买只使用 T 日冻结分支；分支4不新买，缺当日分支证据时入场等待。
普通扫描和批量重载同样只计算该冻结分支。旧混合归档在「买」及次日卖关注视图中
只展示有该分支命中证据的股票，原始结果与历史补算回执保留。用于逐支比较的历史诊断可分别计算，
当日「买」仍只归入其冻结分支。
T 日卖定时任务从精确 T−1 的成功买入归档取名单，按每股原入场分支匹配同名出场信号。
例如分支1买入，次日即使是分支2或4，仍按分支1的卖出时段观察。不同买入分支分别调度，
各组只观察对应股票。任务时段沿已保存信号，窗口内重试不新增任务，完成后不重开。
缺名单或缺原买分支明确等待；不会使用 T 日买入分支补证。停用或未选择的出场信号不执行。
卖名单表示信号关注；模拟账户实际持仓继续使用买入时冻结的出场定义，成交受可卖数量和行情约束。
卖页「建议卖出价」由浏览器逐股计算：买入信号触发价 ×（1＋对应出场信号当前保存的止盈比例）。
按原买入分支取已选中且启用的出场信号，历史缺分支字段时只认该行唯一的原买入命中；
价格、分支或止盈参数缺失时显示「—」。该值是表格展示参考，不写入历史归档或账本。

各信号内部的已启用条件取交集。确认只决定计算时点，行情截止在启动所在的已完成分钟。
策略页“买”的信号评分取该交易日冻结分支：1 为命中分钟相对精确 5 分钟前的涨幅（百分数），
2 为冻结资金分×70%＋技术分×30%，3 为冻结四维综合分；默认降序，同分按已有预选名次和代码，
缺证据显示“—”，分支4不生成买入评分。“卖”的信号评分按同一股票及前一交易日买入归档复用数值和单位。
买卖列表配置均移除 ATR 字段，执行评分、信号命中和账本不替换。
历史评分沿 `services/s05_signal_scores.py` 更新按日视图；原任务状态和归档成员保持。
早盘清仓规则及保存参数保持，未开启监控不执行。

新的本地系统现金回测冻结 `carry_entry_branch_v2`。入场回放仍逐日冻结整数分支，
出场从买入后下一交易日按持仓原入场分支决定，不受当日买入分支影响。
每笔退出按自己的信号触发、截止和分钟容量撮合；停牌按已验证的复牌规则，
确有容量限制的余股继续按原买入分支处理，缺必要行情保留失败，且不把余股计成完整交易。
旧冻结输入（含 `carry_next_branch_v1`）保持对应原口径和历史账本；混入其它出场触发器仍拒绝。

普通现金回测绑定冻结公共行情／研究输入快照的采集时点，记录
`retained_research_snapshot`、输入身份及观察截止；后来采集或修订的数据不证明
历史时点可见，不作为历史实盘归档。严格研究按源日22:00观察截止，
记录`source_day_observed`，并继续执行整份数据的研究治理门。
两者只使用源日及此前的完成日线和对应日期扩展分区。个别评分子项缺失仍取中性50；
扩展源缺失／不唯一、缺观察时点、读取时变化或截止前整份无可见观察仍明确失败。

最近5／15分钟涨幅为启动分钟收盘价相对精确5／15分钟前收盘价的百分数；
允许−10.0～100.0。日内位置为（现价−当日最低价）／（当日最高价−最低价）×100%，
高低相同取50%；开盘缺口为（09:31首根分钟开盘价／昨收−1）×100%，
这两项允许0.1～100.0。四项均可显式null停用，仅用已完成分钟，同股同分钟取最后一条。
启用项缺输入按股票隔离，全部有效价格成员缺条件数据明确失败。
旧冻结输入及归档继续按各自口径读取，不自动重算。

历史日期临时补算标记 `s05_manual_selection_replay_v1` 并保存真实计算时点；
不将补算回执记为原盘后自然执行成功。页面读取归档及按日视图，不现场重算。

## 源码与测试入口

评分入口为 `backend/app/services/s05_scoring.py`，来源冻结与盘后编排为
`backend/app/services/s05_selection.py`，新回放接线为
`backend/app/backtest/minute_replay.py`。S02来源校验和通用行情/财务/扩展读取、
交易日历继续共享，当前入场由通用策略和信号内核执行，未新增Provider能力或公共插件API。

`backend/tests/test_s05_independent_scoring.py` 覆盖旧评分器禁用、固定数值、
中性缺项、前50与同分排序、精确日期/公告、单股隔离和真实Parquet来源读取；
`test_s05_daily_selection.py` 覆盖归档、时窗和保存市场阈值；
`backend/tests/backtest/test_morning_backtest.py` 覆盖旧评分器禁用后的S05回放接线。
Full任务与归档由 `test_full_daily_selections.py`、`test_full_strategy_monitor_tasks.py`
及 `test_s05_identity_rename.py` 在隔离真实PostgreSQL下验证。
安装状态与实际页面验收以本次回执为准，测试夹具不认证自然盘后执行。

`backend/tests/backtest/test_s05_morning_backtest.py`覆盖三个早盘定义、旧冻结口径、
T−1原买分支和当天分支不同、分支4、禁用/混合信号、T+1及容量不足保留成交，
以及冻结研究输入身份、普通采集时点与严格源日22:00的区别。

`test_minute_entry_template_metrics.py`、`test_s05_common_entries.py`和
`test_s05_common_paper.py`覆盖四项范围/空值、API保存、分钟边界与昨收依赖、
所选信号分钟计算、通用归档优先及历史保留、对应出场与分钟执行。
`test_s05_common_daily_branch.py`及`test_full_s05_daily_branch.py`覆盖当前通用META、
精确前日卖名单、原入场分支隔离、缺/错日阻断、任务去重、归档槽、PostgreSQL事务及租户隔离。

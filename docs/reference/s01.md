# S01 策略与接入契约

对象为`s01 / custom_mvxxcs01`。当前策略规则以目标环境保存源码、覆盖及所选信号为准；
仓库中的示例是开发参考，不能替代运行保存值。运行身份见[版本基线](../version-baseline.md)。

## 股票范围与选股

每策略当日股票池是自身股票范围完整列表；板块与自选分组取并集，保留范围区域的
ST和停牌选择。当前要求及本地运行口径为`strategy_scope_v4`；行情缺失、数值过滤、最终命中、
评分及展示上限都不能缩池，旧冻结池不重新标注。工作区源码差异见版本基线。

前日数值过滤按精确前交易日计算，范围含等号，缺值不通过，留空取消限制。
前日价格、涨跌幅、振幅、成交额和上市天数属于数值过滤；当日条件属于所选入场信号。
最近保存值及当前运行状态须从策略详情重新读取，不从历史回测参数恢复。

## 入场与排名

当前S01不再有市场有效股票数参数或数量门槛。上涨比例按完整自身范围中的
有效行情成员计算；无有效成员明确为数据不足，不能作为成功零命中。
使用截至启动分钟的已完成可用分钟累计值，重复时标规范化且成交额不重复累计，
不补造缺行情。

入场时钟、延迟、结束时间及个股门槛来自所选信号。确认时刻与数据分钟分别保存；
实时新入场截至策略交易日14:55:00，整点允许，超过拒绝。持仓退出和历史查询独立。

系统因子`intraday_range_amount_score`的公式为：

`−(当日累计最高价−当日累计最低价)/精确昨收 + 0.001×ln(累计成交额[元])`。

振幅用小数比例，自然对数不加1；原始分数降序，同分代码升序。
评分是否被显式覆盖按当前源码的`scoring_mode`及有效配置解析，不沿用旧研究权重。

## 出场与信号选择

S01专用`s01_morning_exit`新定义完整包含
`decline_3m/volume_ratio_min/start_time/stop_time/fallback_time`五字段。
11:15起的条件收敛为3分钟跌幅至少0.2%且最近3根／此前10根均量比至少1.5；
11:26无条件处理剩余可卖持仓。后续余股处理时钟以实际所选信号保存值为准。
当前源码三阶段机制支持再次触发，不能将时钟信号当作已成交证明。

触发器沿原`entry_signals/exit_signals`选择、应用及保存入口；只在编辑草稿转换旧定义。
显式`trigger_selection=optional_v1`允许取消及多选，独立信号按OR取实际命中、
出场取最早信号；缺失、停用、方向错误和非法参数须拒绝。
旧冻结信号保留原解析，不在读取时迁移或补回已删除条件。

## 卖／选／买与回测

显式`result_sections=signals`开启每日结果：
卖读取同策略精确前交易日成功买入信号归档；选读取目标日完整冻结预选；
买只从该日已保存预选中确认。实际持仓退出独立计算，三页名单都不等同成交。
单股参考证据异常保存代码、原因和覆盖计数，有效股票继续，完整池保留；
无法定位单股的整份证据错误及全无有效成员须明确失败。

资金、仓位和费用属于公共回测或实际账户配置。新公共回测
`common_backtest_v1`等权单票目标为净值×最大总仓位÷最大持仓数，
未用名额保留现金；评分加权使用正分归一化，无正分时等权。
信号与成交时点分开，真实分钟容量、整手、T+1、停牌及分片累计费用共同限制成交。
缺数据或截止仍有余股时保留真实成交及余额，拒绝完整净值认证。

选择通用尾盘建仓触发器时，14:45输入分钟与延迟后的确认时钟分别判断；
确认可晚于输入分钟，不能再用固定14:45剔除已经确认的事件。历史回测无实时观察时钟时，
使用该触发器保存的确认时间；实时扫描仍受实际观察时钟和已完成行情约束。

## 实现与验证入口

共享内核在`strategy/builtin/_overnight.py`，信号解析在`strategy/s01_signals.py`，
持仓适配在`strategy/overnight_runtime.py`，回测在`backtest/overnight.py`。
`META.entry_window_policy=available_minutes_v1`由源码解析为内部运行标记，
不能通过参数给旧冻结定义开启新语义。

验证须覆盖保存源码及备用入场路径、所选信号、重复分钟、完整池、独立持仓退出、
旧冻结定义、真实容量与累计费用，并实际选择S01检查历史、缺档、无摘要及三页切换。
本页不保留历史收益或旧测试计数；本次文档清理未运行收益回测。

2026-10-31资金规则调整：`entry_nav_fraction=0.2`，`participation=0.1`。
`entry_budget=0`表示不加固定金额上限；旧配置的正数仍作为额外上限生效。
净值只使用现金与当时已观测持仓价格，后续委托不回到先前成交分钟之前，
不使用当日收盘估值决定买入数量。旧研究账本保持历史冻结，不能当作新版结果。

回测仅支持连续资金的「仓位模拟」。资金、费用和卖出规则使用上述策略参数，
通用成交口径与独立止损止盈不适用。费用按同证券、同日、同方向的汇总委托计算，
分片记录增量费用；遵循T+1、现金约束、股票申报数量及指示性涨跌停限制。
结果可查看并下载全部成交分片和卖出信号。

`sell_deadline`默认13:30，可显式设回11:29以复现旧期限；早盘触发规则保持。
截止时间必须晚于兜底信号且是有效交易分钟，不接受午休时点。

缺交易日或分钟分区、缺完整有效早盘、缺原始估值，或13:30仍有卖出余股时，
结果保留已经发生的成交、剩余持仓与现金，并返回失败原因，不生成完整收益曲线。
监控缺指标时关闭受影响指标分支，时钟兜底仍可产生信号。

持仓信号监控只读取已有模拟账户中 `entry_policy.strategy_id` 归属于该策略的
实际成交持仓与T+1可卖数量。当前模拟账户自动委托不支持容量分片，因此拒绝将
此策略的信号转换为旧快照撮合订单；信号提示不表示已经卖出。未接入实盘下单。

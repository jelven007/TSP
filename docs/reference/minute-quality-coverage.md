# 历史分钟覆盖与停牌证据

历史数据覆盖判断须先读取当前数据发布中的
`instrument_status/suspensions.parquet` 及
`instrument_status/confirmed_full_day_halts_*.json`。
核对来源、证券代码、明确的停牌及复牌边界、公告发布时间和文件指纹后，
按股票日排除已证实的全天停牌。缺日线、缺分钟、零量及当前 ST 名称本身不证明停牌。

历史全天停牌事实与当时可用的策略证据分开计算。上述 JSON 的
`scope=historical_quality_only` 只用于历史质量审计；不得把事后公告倒填成
开盘前可用证据，不改变 `dated_status(..., observed_at=...)`、
当日股票池、策略回放或冻结回测的时序规则。

每次审计读取当前发布证据并复算证券日、可交易日、分钟键和完整覆盖率，
逐项记录证券日、来源链接、原文、PDF 哈希及真实公告时间。
事后确认的全天停牌可以解释历史质量缺口，但不能成为当时可用的交易信号。
不能硬编码证券名单绕过验证，也不能为停牌日期补造 K 线。

覆盖率只说明本次目录内的键覆盖，不证明完整历史上市/退市股票全集，
也不消除量额精度或其他实测质量问题。当前数据来源及待验收项见
[市场数据契约](market-data.md)和[当前验收边界](../planning/current-validation.md)。
